# 架构、原生代码与证据强度

## 可支持的技术判断

【包内条目】基础包有 .ccbi、.plist、.atlas、PNG、MP3、TTF 等资源。CCBI 的分卷命中为 part01 612、part02_1 174、part02_2 36，总计 822，与本机清单相同。

【字符串线索】reference-inputs/native_关键词字符串.txt 第 4–11 行含 MCEngine/src/MCCocos2D、MCCCBReader/NodeLoader 路径；第 625–626 行含 Cocotron/Foundation/NSString。第 1273 行有 AppDelegateCarrom.mm，第 1583 行有 nucleus/AppDelegate.mm。它们支持“Miniclip 自有 MCEngine / Cocos2D 风格资源与原生层”的架构候选，不支持确定 Cocos Creator 版本，也不是 Unity IL2CPP 证据。.mm 残留路径说明编译来源命名，不等于恢复了对应源码。

【配置正文】CyclePromoArrow.json 的 skeleton.spine=3.7.94，证明这份动画导出数据的版本；不代表整个引擎或所有 Spine 资源统一为该版本。

当前没有 ELF 头、动态导入、JNI 绑定和反汇编，故引擎精确版本、物理库、加密格式、实际启动调用链全部未确认。

## 三条重点行为研究链

以下是下一步取证链，不是已验证调用图；箭头表示研究顺序。

### A：输入到出杆

候选：createStrikerBarDelegate → setupAimControls → gameplay_shot_taken → TableLogic。native:3038–3048 存在对应函数模板；4736–4750 有 enableInputStrikerBar / disableInputAllStrikerBars / enablePuckTouch；5104 有 nodeWithStrikerId:level:buffId:power:aim:time:contentSize:。这说明位置、瞄准、力度与时间存在独立命名面，不能由参数类型推得力度曲线、输入窗口或触控取消行为。需要主库函数交叉引用及真实手势录像。

### B：运动结束到规则结算

native:2659–2663 的 puckPotted(int,int)、puckPocketed(int,int)、puckReturned(int)、physicsStopped()、strikerPocketed(int) 是不同回调名称。native:3035 的 MatchControllerTurnBased::physicsStopped、3042 的 scorePucksForTeam、3007 的 MatchControllerCarrom::physicsStoppedExtra 提供研究入口。不能把 potted 与 pocketed 擅自合并，不能断定先计分后犯规或先 Queen 后胜负。需要同杆多事件、停止检测及结算提交 owner 的代码证据。

### C：广告机会到奖励

native:3001 包含 RewardedVideoManager::showVideoForPlacement，3008 包含 RewardedVideoPlacement::sendTokenRequest；2099、2117、2118 分别含 ad_reward_token_request / consumed / response。GoldenShot、SeasonPass、LoginCalendar 等调用方名称共现。可推断存在按 placement 和奖励 token 组织的协议设计候选，不能证明 token 真正由服务器签发、回调幂等或到账成功。需要匹配请求定义和取消、失败、完成三种受控记录。

## 检索反例与局限

physics 命中 physicsAnimating、physicsSpeedFactor 与停止相关符号；小写 collision、friction、interstitial 未命中。这是经过关键词筛选、非完整字符串集，且 grep 为字面匹配；零命中不证明未使用碰撞、摩擦或插屏。native 索引混有 CodeReview 与 Gold-Release 路径，可能为编译残留或模块组合，未建立版本配对；不得把路径当作两份可执行构建，更不能套偏移。

GameConfiguration.plist 和 framedSprites2.plist 文本读取被拒；en_text.plist 提取至研究代码目录时被判二进制；verification.properties、client_analytics.proto 读取也被工具拒绝。上述均是访问/格式边界，不是解析后证明损坏、加密或无配置。
