## 3. 几何核算及排除条件

令单位方向 u=(P-A)/|P-A|≈(-0.707107,-0.707107)，路径中心 C(s)=A+s*u。

- P-A=(-20.5061,-20.5061)，L=√(2*20.5061²)≈29.000004。
- B-A=(-32.5269,4.2426)。a=(B-A)·u≈20.000，p=|cross(B-A,u)|≈26.000。
- 起始两棋中心距 √(a²+p²)≈√1076≈32.802，超过半径和32约0.802；**不是初始重叠夹具**。
- 完整 A→P 中心线到 B 的最近点在 s≈20，最小距离≈26；小于物理半径和32，也小于历史 width30 的启发式半径27。width 是调用参数，不可擅自理解成半宽15；启发式阈值27与物理半径和32也不能混为一谈。
- 首次圆盘接触的路程为 `s_hit=a-√(32²-p²)≈20-√348≈1.345`，接触时目标中心约(80.555,381.555)。这是接触临界；继续向前即进入几何重叠区。
- 无障碍、沿同一直线时，到达入袋区的路程 `s_pot=L-20≈9.000`，目标中心约(75.142,376.142)。由于1.345<9，障碍会先被接触。
- 即使将中心路径截断到入袋边界 [0,9]，其到 B 的最近距离约 `√((20-9)²+26²)=√797≈28.231<32`。B 的中心投影20虽在捕获路程9之后，圆盘的近侧边缘仍会提前挡路；不能只因 a>9 就排除它。
- B 到袋口中心约 `√((20-29)²+26²)=√757≈27.514>20`；A 到袋口约29>20。因此两棋均不是初始已满足入袋距离的对象。B 的圆盘覆盖捕获区部分空间不意味着其中心已入袋。
- 代入摘要墙体，普通棋中心的无穿墙范围为 x∈[47,593]、y∈[348,901]。A、B 均在内；B 到左墙中心距17.979，减物理半径后余量约1.979。A 沿 [0,9] 到捕获边界的中心仍在该范围内。该例不能简单以“障碍在墙外/先撞左墙/起始已在袋里”排除。但这只是指定圆与矩形墙模型下的合法性，未证明完整自然局面、其他棋或现版隐藏约束合法。

坐标仅四位小数，上述 along/perpendicular 按摘要整数近似做接触演算。毫米级（此处游戏坐标0.001量级）舍入不足以改变约7.655的接触先后差与约3.769的捕获截段半径余量；不能用舍入解释本例。然而离散时间步、求解器接触容差、速度、阻尼、障碍速度、传感器状态及检测顺序未知，故本次不是动态首次碰撞时刻证明。

## 4. 局部覆盖、可能误判与不能推广的结论

### 已支持的覆盖缺口

按现版摘要，正宽度 w 下 0<=L<w 的局部检测提前放行；本例29<30。false 表示此函数未报告阻挡，不表示物理可进袋。其他位置的起点保护即使排除此候选，也不能使此处的局部 false 变成 true；反过来，本处没有保护表达式不证明整条 AI 管线没有其他否决。

历史非短段检测的轴向核心区间从 w 开始，到 floor(L/w)*w 结束；带半径的端帽可以覆盖区间外一部分，但不是完整 [0,L] 的保证。因此短段、起点附近、尾段、阈值半径差、开关关闭应分别测试。不能从本例直接声称所有这些缺口在现版均存在，或所有 L<w 都产生业务漏判。

### 业务判断必须分层

审查链条为：在场局面 → 各方向/开关过滤 → 目标至袋口检查 → 起点与击球接触可行性 → 候选评分/排序/随机偏差 → 出手提交 → 物理演化 → 入袋移除 → 回合结算/计分/胜负。

E-01 仅报告一次中间调用及 false。未提供候选列表、开关实值、起点、接触角、最终选中条目、力度、实际轨迹及结算。本例说明该局部检查可能把“沿方向存在先接触”的路径当作未阻挡；碰撞之后能否间接进袋、仍可作为组合球、或已由别处剔除，均未知。不能把几何接触直接定义为整局失败。

### 合理排除/对照条件

- 圆盘不在参与检测与碰撞的集合、已移除/已入袋、sensor或碰撞过滤禁用：应按实际生命周期确认，不仅看画面。
- 初始重叠、NaN/Infinity、非法宽度、墙外位置：应与合法漏检区分，不能混作同一修复证据。
- 捕获之前完全不接触而只在之后接触：若入袋即移除，该段通常不应因后续碰撞被否决。须用首次接触路程判定，不仅看障碍投影。
- 几何静止模型不含障碍运动、多次碰撞、击球误差和反弹。不同球种、模式、视口坐标变换、自然可达布局、竞品均未覆盖。

## 6. 实现变更的风险（没有实施）

1. **仅将 floor 改 ceil/至少一步**：会采样到L之外，本例强行采样30已经超过袋口中心29，更超过实际捕获路程9；仍不定义完整短段中心覆盖和业务终点，可能新增误阻挡。零长度强行检查也改变契约。
2. **直接改为 [0,L] 最近点检测**：需要显式排除移动棋自身。历史函数合并全部在场棋且没有身份参数，起点检查若包含A会自阻挡；按坐标排除会错误忽略真实同坐标障碍。新增身份参数还需逐调用点识别递归/组合球中的移动物体，不能只按函数名替换。
3. **直接 OR `_carromStartPathBlocked`**：历史半径为37.76（击球器21.76+普通棋16），不是普通棋对普通棋32；默认与fallback的长度语义不同，intendedTarget排除方向也不同。盲目传入移动目标可能误排除障碍，传null又可能自阻挡；不推荐仅凭名称复用。
4. **扩大27至32**：减少物理意义漏检，却会改变历史启发式意图、长段候选数、评分分布、组合球与回退触发率；本例无需扩大27也能被完整短段几何捕获。因此半径变更与轴向覆盖修复应拆开评估，不能伪称只是补一行且行为不变。
5. **截到入袋距离20**：更贴近移除语义，但须处理L<=20、非中心瞄准、离散触发顺序、sensor、棋种/模式变化和墙角。不能单纯丢弃投影超过截段的障碍，本例就是反例。
6. **全局改动所有调用点**：可能破坏起点段、反弹段、递归组合球的端点语义与候选分布。优先风险较小的候选方案是：保持其他段原契约，独立明确目标段的移动棋身份、合法障碍集合、半径政策及有效终点，隔离测试后才决定是否接入。此为建议，不是用户确认或补丁。

未来如授权修复，应先保存基线字节与失败夹具；分别比较局部返回、候选数量/分布、最终选择及动态结算，再建立可回退路径。本次没有进行这些动作。
