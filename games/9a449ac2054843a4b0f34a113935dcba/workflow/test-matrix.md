# Carrom 有向评分精确测试矩阵

## 状态与执行纪律

**本文件是可执行的用例规格，不是已跑测试。所有用例状态均为 NOT_RUN。** 本轮仅做静态审查和数学推导，未运行测试脚本、VM、Planck、浏览器、设备、npm build/test/check。

证据编号与原文件路径见 `/workflow/source-review.md`。验证必须分层：

- L0 数学/评分表达式探针：可单独复现八个 dot 表达式和阈值；不代表生成器可达性。
- L1 真实源函数合成VM：读取原文件、解析其实际函数并调用；保留真实坐标过滤及路径辅助，记录每个分支拒绝理由。若为阈值探针暂时固定阻挡结果，明确标作 probe，不把它当完整生成器。
- L2 原游戏 Planck 完整射击/回合：真实资源与板夹具、物理半径、规则依赖及AI执行链，记录首次接触/入袋/犯规。
- L3 浏览器/设备：当前实际构建、固定环境和输入、控制台及性能。不能以L0/L1替代L2/L3。

每次输出：源文件SHA256、harnessSHA256、seed/随机序列、依赖版本、板夹具、球对象身份及坐标、模式/红球状态、采样S、G/H、B、theta/alpha/beta、原始dot、k、最终score、best、分支/拒绝原因、候选pos/dir/dist、实际力度/误差、首次碰撞顺序、结算状态。对old/signed逐候选配对，不只比较总数。

数值容差：L0角/点积默认1e-10、几何坐标1e-6px。严格阈值用直接设置score的表达式探针验证，避免cos(π/3)浮点略大于0.5干扰；端到端另测±1e-6。L2首次接触允许误差需报告实际Planck接触容差与步长，不预先编造“已符合”。输入窗口从原游戏状态门禁取证，不另造计时玩法。

L1固定假设夹具建议：board={x:40,y:340,width:560,height:560}；袋=[(61,362),(579,362),(61,886),(579,886)]；baseline y=421，x=[162,483]；rCoinAlgorithm=15，rCoinPhysical=16，rStriker=21.76。**该board仅为显式合成假设，不是原资源实测尺寸。** L2必须替换成真实板/墙数据后再跑。
