# Carrom AI 有向评分独立只读审查

## 1. 结论与审查边界

本次为 prototype 阶段独立源码审查，不修改游戏，不开发替代游戏，不推进美术、代码或测试阶段。恢复轮次 attempt=2，上一轮连接中断；本轮补读角度辅助、投射方法及物理步长，并交付报告。全部运行测试均未执行。

- **PASS（静态方向语义）**：所定位八处将绝对值点积改成有向点积的符号正确。直击比较 S→G 与 T→P；反弹比较 B→G 与 T→P，而不是 S→B 与 T→P。对非退化、静止球、单次首次接触模型，负点积不能在指定接触点把 T 推向 P，去掉绝对值有依据。
- **PASS（静态递归结构）**：组合球只有一层，子候选写入父数组；递归系数不是完整父候选评分。有效非零方向受同一个函数的象限限制，父子方向点积非负，不能仅凭四处残留 abs 认定反向组合球实际可达。
- **NEEDS_CONTEXT（合法球覆盖）**：不能证明整个生成器不漏选。阈值、稀疏基线采样、象限/高度限制、右上直击不对称、路径检查及真实碰撞半径均是独立风险。有向修正只否定指定几何路径，不否定真实棋盘上存在另一条合法路径。
- **BLOCKED（运行与体验）**：上传统计未独立复跑；没有 Planck 完整回合、浏览器或设备证据。不能判断胜率、犯规率、设备性能或体验提升。
- **NEEDS_CONTEXT（全文件唯一差异）**：已确认所读候选函数八处评分变化，未完成两文件逐字节完整 diff/hash 校验，不宣称全文件仅这八处变化。参考目录的哈希样式名称不等于本次文件哈希测量。

## 3. 公共方向定义与物理理由

屏幕坐标 x 向右、y 向下。`_0x8b2762(A,B)` 返回 `atan2(B.y-A.y,B.x-A.x)`；`_0x2bd695` 是欧氏距离，`_0x16430c` 是折回 [0,π] 的最短夹角，但后者不是八处评分的接纳依据。

记目标球 T，袋中心（子层则为虚拟目标）P，击球器起点 S：

```
theta = angle(T,P)
n = (cos(theta), sin(theta))
R = rCoinAlgorithm + rStriker = 15 + 21.76 = 36.76
G = T - R*n
u = unit(G-S)                         // 直击入射
v = unit(G-B)                         // 反弹后段入射
oldScore = abs(dot(n,u或v))*k
newScore = dot(n,u或v)*k
```

G 是击球器中心的虚拟接触位置，不是 T 的中心，也不是袋。若两球静止且首次接触恰在 G，则 G→T 的碰撞法线为 n；只有入射速度向 n 有正投影才是逼近接触。在 G 点负投影意味着分离；如果无限直线仍穿过目标的接触圆，首次碰撞会在 G 之前，届时碰撞法线已不是期望 n。abs 把这类反向几何也评成高分。

真实投射链：AI `_0x4b3cc6` 传入 `a=π-candidate.dir+error`；击球器 `_0x13fb80` 的投射方法用 `(-a+π)` 生成速度/冲量方向，因此净方向是 `candidate.dir-error`，error=0 时就是生成器方向。不存在由该转换造成八处评分应整体取负的问题。误差的正负会翻转，但对称分布范围不变。

### 不只是候选删除

每目标 best 从 0.5 开始，必须 `score>0.5 && score>best` 才接纳；理想基线点成功则 break。`best<0.7` 才查反弹；`best<=0.5 && !outputAccumulator` 才查组合球。负评分被删除后可重新打开反弹/递归分支。因此不能普遍断言新候选列表就是旧列表的子集，也不能用某批次数量未增加推导所有场景都不增加。0.5/0.7 边界比较保持严格语义。

## 5. 一层组合球引用语义

生成器六参数：`(P,targetList,checkOutgoingPath,outputAccumulator,parentOutgoingAngle,parentOutgoingDistance)`。

顶层 T→P 没有合格直击/反弹时设 `Q=T-30*n`，用同一个袋函数调用 `generator(Q,allDiscs,true,parentArray,theta,distance(T,P))`。子层把其它球 A 当目标：

```
phi = angle(A,Q)
m = unit(Q-A)
H = A - 36.76*m
k = abs(dot(n,m))
childScore = dot(unit(H-S或H-B),m)*k
childDist = distance(A,Q) + strikerPathDistance + distance(T,P)
```

四处 k 分别 `_0x1602ce`、`_0x4fcd0f`、`_0x873a71`、`_0x5b321d`，仍为 abs。k<0.5 跳过；最终乘积仍须严格 >0.5。因此 k=0.5 理论上不能接纳（入射 dot 最大1），k=0.8 时要求入射 dot>0.625。父距离只加进 dist，不是父评分乘进 hDot。子层通过 truthy 父数组累积，自己的返回空数组不表示失败；truthy 累积器禁止再递归，最多 T 与 A 两目标球组合。

### 残留 abs 与几何可达性

非退化且通过坐标筛选时：左上 theta、phi 均在左上象限，右上均右上，左下均左下，右下均右下，两方向夹角最多90°，点积非负。此时 abs 对符号冗余，k<0.5/最终阈值继续排除大夹角。这是由调用同一函数且子层 Q 被当袋的过滤得出的，而非“所有组合球方向天然正确”。

`allDiscs` 包含原 T，但有效 T 会被子层象限筛选排除：Q=T−30n 位于 T 的反出射侧，T 不在 Q 的允许目标侧（非零 n 至少一个坐标违反筛选）。不能把“列表含 T”直接定性为有效自撞候选。没有显式身份排除仍是鲁棒性关注点。

退化 A=Q、T=P、距离/角度非有限等不受上述单位向量证明保护。atan2(0,0) 给0并不表示存在实际出射方向；上袋等号条件可能允许零长目标。原 T 的身份排除、零长向量过滤及状态损坏需单独测试，不能给无条件 PASS。另一个更现实的风险是象限筛选过强：物理上正投影的跨象限组合也可能被排除；应先构造合法几何再评估是否希望拓宽策略，不能直接把四处 abs 全换成 signed 就称修好。

## 6. 未修复的风险与误排除范围

### 6.1 半径不一致——本轮新确认

候选 rCoin=15px；物理 `_0x54e9a5` 球夹具半径16px。击球器算法/夹具均21.76px。虚拟接触 R=36.76，而真实中心接触距离为37.76；组合 Q 的偏移30而两物理球接触距离32。故即使 signed>0.5，也不是精确物理接触法线或入袋保证。

在直线模型中令 c=dot(n,u)，到 G 的路径长L、实际接触圆半径Rc，首次接触参数

`tFirst = L + R*c - sqrt(Rc² - R²*(1-c²))`

适用于判别式非负、起点在圆外且交点位于射线时。若 Rc=R，c>0 首次接触恰为L；c<0 则提前 `−2R*c`。若 Rc=37.76，c>0 仍提前

`delta = sqrt(Rc²-R²+R²*c²)-R*c`。

顶层 c>0.5 时 delta 在约1–1.93px之间（数学模型，不是物理实测）；这帮助解释“无 >2px 提前接触”的合成指标，并说明0不意味着没有提前接触。路径辅助对 intendedTarget 的整体跳过不能修正此误差。

### 6.2 策略本身不完备

- 正点积≤0.5 的浅切球可在物理上合法，但阈值仍排除。这不是改动新引入：旧 abs 对同样正点积也排除。
- 直击查理想基线交点加六个等距点，反弹仅四点；不能覆盖连续合法位置。上袋仅 T.y<421 做直击；下袋需 T.y≥436 且 T.y<P.y。象限/高度筛选可漏真实路线。
- 右上直击等距点仍要求 `S.x<=T.x−36.76`，与左上相同；理想点不受该限制。这是原有镜像不对称的候选漏选风险，不是八处 signed 补丁引入。需镜像测试，不把所有右上直击说成被禁止。
- 只搜索三类指定反弹墙；没有所有单墙、更没有多墙/其它组合穷举。非镜面能量损失、相撞顺序、球运动与墙角几何都未由点积表示。

### 6.3 阻挡与墙几何

`_0x23a7dc` 仅检查 allDiscs 中中心距离 <指定半径，无板边界检查。`_carromStartPathBlocked` 检查前 min(L,43.52) 的胶囊，半径37.76，跳过 intendedTarget；bank首段传null、后段传T。

`_0x3ea989(origin,d,angle,L)` 用 floor(L/d) 个样本，steps<1 直接false。击球器 d=43.52，原样本半径39.168、补缝37.76；目标路径 d=30、原样本半径27、补缝27。它不跳过 intendedTarget 或运动源球。末端余段、近源段、粗半径误杀、对象自身与组合原目标需分别检查。不能称完整连续碰撞检测；并且目标物理球间半径和32，不等于27。

墙中心线用 board 的运行宽高：底=board.y+height−26−21.76，右=board.x+width−26−21.76，左=board.x+26+21.76。未见完整 B 在墙段内、角落避让、额外先碰另一墙的校验。真实 board 尺寸依赖资源，本次无完整资源/运行测量，不将硬编码袋中心当完整板夹具证据。

### 6.4 真实选择、力度和随机误差

AI `_0x50a0ff` 合并四袋候选，检查有限 pos/dir/hDot/dist、dist≥0、x∈[162,483]、y===421、基线不重叠后按 hDot 降序取首个。Freestyle 全球；普通模式只剩一颗AI球且红球仍在则优先红球，否则AI球。

候选 speed=`10+(1-score)*100` 不是实际发射力度控制。实际 dist 换算因子 `1/100*60*0.2*1.1*1.25=0.165`，上限125，dist≥125/0.165≈757.575758 即饱和。未补偿反弹/组合传能损失。五桌随机角误差触发概率数组 `[0.8,0.7,0.6,0.35,0.2]`，误差幅值0.05–0.1rad，不能用无误差合成评分代替实际效果。

### 6.5 无候选与回合生命周期

无候选有 `_0x3d12d7` 随机目标/基线回退。2px 轴向找位置不足时，用 `_carromFindOpenBaseline` 合并阻挡区间查空隙。近源挡路尝试7个基线点；全无无遮挡替代时仍保留原回退（源码明示），返回只有pos/dir，实际默认力度100。保证的是尽量有合法放置，不保证进袋、不犯规、全过程无遮挡。

无目标或基线全堵可返回null。普通情形交给玩家；红球待cover/Freestyle pending走当前回合结算，防止绕过红球状态。`_0xd6b627` 快照→移动/瞄准动画→`_0x4b3cc6`，执行前检查快照与基线；位置变化阈值1px，失败最多2次回退重试再结束回合。异步暂停、换局和结算不能由候选生成统计验收。`game.test` 的早 return 后候选调试代码不可达，不能把它当测试入口。

## 8. 轻量性判断与建议

八处没有增加搜索层数、物理模拟或采样数量，单次点积仍常数开销，属于小范围策略修正。但实验版每次评分写内联箭头恒等函数，可能有临时函数/调用开销，是否优化由JS引擎决定，未实测。不能把“移除abs”直接叫更快；反弹/递归分支可能变得更多。

目标数Nt、全球数N、路径样本数M时，基本路径检查约 O(Nt*N*M)，顶层逐目标触发一层遍历全球时最坏可到 O(Nt*N²*M)，Nt≈N时为 O(N³*M)，另有合并排序 O(C log C)。这是结构量级估算，不是性能基准；局面阈值、分支提前退出显著影响真实开销。

可操作优先级（建议，不在本轮实施）：
1. 补齐两文件完整diff、harness/seed与板夹具，先跑矩阵中的八处符号及上传两反例，避免以总数替代逐路径证据。
2. 核对15/16半径不一致、组合30/32偏移与第一次接触法线；是否改接触几何应返回代码阶段评估，不随此次审查直接改动。
3. 独立检查墙段范围、余段/粗半径和右上镜像筛选；不要把未改风险归到signed。
4. 对无候选回退、红球/超时/暂停执行完整回合，再讨论体验；用固定随机序列比较，不只比较候选排名。
5. 轻量性必须对当前完整运行测生成器时长、调用次数、GC与目标设备分位数，不能引用上传VM毫秒作为验收。
