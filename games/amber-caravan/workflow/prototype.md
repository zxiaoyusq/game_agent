# 琥珀商路 · Amber Caravan

## 目标与来源

将用户指定的 Just Ludo 和 Ludo Superstar 重构为一个可独立运行的 H5 游戏。新增明确约束是非洲或中东风格；选择摩洛哥绿洲商旅，覆盖背景、棋盘、棋子、配色、UI 与反馈。整份交付工程（含源码、资源、测试、报告、截图与可运行构建）压缩前与 ZIP 均不得超过 10,000,000 字节。

参考方法与原包证据见 `reference-analysis.md` 和 `reference-inventory.json`。使用工程的 casual-game-production、game-reverse-engineering、engine-identification 与 H5 换皮的索引/对照方法。用户要求的是融合重构，因此不是只替换图集的任务；原脚本/布局不变的“纯换皮”限制不适用。没有使用未经安装验证的引擎工具或宣称调用生产工作流 API。

## 融合取舍

| 来源优势 | 新作行为 |
|---|---|
| Just 的快速局、合法棋高亮、安全标识、策略电脑 | 保留吃子解锁快局、落点预览、星形驿站、独立 AI |
| Superstar 的清楚模式入口、本地对战与续局 | 大厅集中选路线/人数/人机或同屏，每次有效动作后保存 |
| 两者共用的经典 Ludo 核心 | 六点出营、单子吃子、精确归家、奖励掷骰、四子经典胜利 |
| 原作厚描边平面资源 | 全新摩洛哥庭院板面、黄铜八角罗盘、宝石棋子与绿洲插画 |

以下为主动的新设计，不能冒充原作原样规则：

- 公平骰子：人类与 AI 共用系统随机源，不继承皮肤、首局或难度的隐性概率。
- 连续第三个六点罚停；原包是第四次六点重抽。
- 普通格敌方两枚叠子禁止落入，但允许经过；原包允许混色共存。安全格始终可共存。
- 2/3/4 人均以首位冠军结束，不继续原作四人排名。
- 同屏全部为人类；人机为一人对其余电脑。没有虚假的联网匹配入口。

## 规则与主循环

动作：掷骰 → 突出合法棋与当前玩家 → 点击棋子/编号按钮 → 沿路动画与事件反馈 → 奖励再掷或换人 → 完成目标 → 结算/再来一局。

- 四个阵营，每队四枚棋子。两人使用对角阵营；三人/四人按环顺序轮流。
- 52 格共享外环，每色相差13格。安全格为 `[0,8,13,21,26,34,39,47]`。
- 正常相对进度 `-1` 为营地、`0..50` 外圈、`51..55` 私有归家道、`56` 终点。每队回家跳过起点前那一格，与原配置路径一致。
- 掷6可将营地一枚放在起点，也可移动已有棋子6格。点数必须恰好到终点，不能越过。
- 非安全格落在单枚敌子上，将其送回营地。吃子、归家或掷6提供一次额外掷骰，不叠加多次奖励。
- 连续第三个6不走子，立即换人；没有合法动作自动换人。
- 经典远征：四子都归家获胜。
- 疾风商路：两枚初始都在起点，其余在营地；先吃过至少一子才能归家，任意一子归家获胜。未解锁可以无限绕52格外环。`outerLast` 明确区分外环末格与归家道51，解锁不会瞬移另一枚棋子。
- AI 只能选择 `legalMoves`，综合归家、吃子、安全、风险和推进，不能预知骰子或改骰子。

## 技术与交互

使用原生 ESM、SVG 和 HTML/CSS：这个棋盘项目不需要复制两套 Cocos 运行时，可更容易保持极小包体、清楚模块与可测试规则。SVG 是实际运行的矢量美术，背景是实际生成插画；没有以设计稿冒充运行资源。

`rules.mjs` 只处理可序列化数据与动作；`ai.mjs` 只选合法棋；`board.mjs` 只呈现；`app.mjs` 拥有计时器和输入；`storage.mjs` 处理读写失败；`audio.mjs` 合成音效。

目标为现代桌面/手机浏览器。操作支持鼠标、触摸、键盘。小屏棋盘很细，另提供四个至少44px高的编号选择按钮；不把小棋子作为唯一点击入口。布局允许短屏纵向滚动，不横向滚动。用户选择减少动态效果时关闭动画；设置可切快速节奏/声音。弹窗限制焦点并支持 Escape。

单局时长受骰子与选择影响，不向玩家承诺未经实测的分钟数。没有限时、金币、商城、付费或在线服务。

## 存档与生命周期

每次规则提交保存合法局面和偏好；JSON结构、棋子范围、门锁、胜负、阶段等读入验证，坏档回大厅并给提示。存储失败持续提示，不能假称保存成功。局面先提交再动画，因此刷新不会重掷已经提交的骰子或重复吃子。暂停、退出、切后台取消计时器；恢复从当前状态继续。获胜状态可以从大厅再次打开结算。

## 验收条件

1. 原包身份、规则证据、原菜单和对局截图齐全。
2. 两种新模式支持2/3/4人；AI与同屏能完成合法全局；胜利后能再开。
3. 规则覆盖出营、安全格、叠子、吃子奖励、精确归家、三六罚停、快局锁门跨圈等边界。
4. 真浏览器从大厅点击开局、掷骰、选子直到结算；不注入胜利局面。覆盖暂停、恢复、刷新、坏档、无存储权限、音效偏好、手机布局。
5. 新旧画面同状态对比；新主题明显符合摩洛哥/北非方向，资源全换，文本与棋子可读。
6. 发布不依赖第三方资源；构建入口可用；完整工程和网页包均低于10MB，列实际字节。
7. 报告明确浏览器与真机边界、主观审美限制、原在线模式未迁移事实。
