# 独立视觉核验：琥珀商路与两个原始 Ludo

核验日期：2026-11-03。核验对象为修正后重新构建的磁盘 `dist`，以本地静态服务器 `http://127.0.0.1:24733/` 实际运行。浏览器：Linux Chromium / Playwright；桌面 1440×1000，移动模拟 390×844；三列对照另用 420×900，DPR 1。**这里的 mobile 是浏览器移动视窗，不是真机。** 没有以美术设计稿代替实际页面。

## 结论

新作已经从原版的蓝/紫色休闲游戏大厅、塑料感四色棋盘，转为摩洛哥庭院、暖象牙瓷砖、黄铜边饰和宝石商队棋子的完整主题。菜单、棋盘、棋子、图标与信息结构同时变化，可以认定视觉重构清晰，且“非洲或中东风格”由摩洛哥拱廊、几何花砖、棕榈、灯具与暖沙色共同支撑。

从主题一致性、材质层次和桌面空间组织看，新作比两原作更精致。**不能据此声称每项可读性都更好**：原作高饱和四色更容易一眼区分；新作手机棋盘内的小字与淡色路径较弱，初次核验发现的开局滚动、开始按钮首屏不可见、桌面侧栏承托不足均已在本轮修复并重新检验。仍保留小屏次要文字偏小、颜色对比不及原版的观察。

## 本轮操作与量测

1. 三种视窗分别从空白存储打开菜单，实际点击“经典远征”→“开启旅程”。
2. 桌面页面宽/视窗宽为 1440/1440，高/视窗高1000/1000。
3. 390 视窗页面宽/视窗宽为390/390，经典对局高/视窗高975/844；420 视窗为420/420，高1005/900。不存在横向溢出；纵向内容超出视窗是实际结果。
4. 新开快局自然点击骰子，本轮随机得到2（没有改 RNG 或注入棋子状态），再点击首个合法编号按钮；回合提示、棋子位置与日志发生正常变化。
5. 新作这组操作没有观察到 JavaScript `pageerror`。此处不是完整性能/规则验收，也不代替主流程测试。

- **PASS**：三种视窗真实打开、经典对局真实入场、快局实际掷骰与选子；主题变化、多数材质与排版差异都有截图证据。
- **PASS**：三列同宽对局对照图已落盘；来源、模拟设备范围、截图状态差异已标注。
- **PASS**：三个已反馈的布局/流程问题均在最终构建重新检查；390/420视窗开局与返回大厅回顶部、390首屏开始按钮可见、桌面侧栏承托都有当前运行证据。
- **NEEDS_CONTEXT**：本独立视觉检查没有真机、屏幕阅读器、色觉模拟、长时间动画性能或完整胜局覆盖；相关结论应以主测试报告补足。
- 视觉“更好”含审美判断，本报告将它具体化为主题一致性、材质、版式与可读性逐项比较；没有用单一分数替代用户的风格判断。
