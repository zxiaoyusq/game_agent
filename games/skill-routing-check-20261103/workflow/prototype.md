# 4×4拖拽合成原型定义

## 原型主文

本项目是浏览器原生Canvas 2D单局合成游戏，面向鼠标及触屏，不加载Cocos。目标为通过拖拽二合一获得一枚五级棋子。采用固定棋盘而非随机关卡：4×4共16格，开局每格一枚一级棋子，按行分配唯一身份。预计单局2至4分钟，此时长是待试玩确认的假设。无时间、步数、体力、货币、生产器、订单、出售、撤销和跨局成长；没有参考游戏或本地参考文件，规则来自本项目简报与冻结资料。

核心循环为观察等级、选择棋子、拖向空格或同级目标、查看移动或升级反馈，再寻找下一对。全部16枚一级棋子的基础投入，依次经8次一级合成、4次二级合成、2次三级合成、1次四级合成，最终得到五级，共15次合成。移动不消耗步数或资源，合成只消耗两个输入棋子，不生成额外新棋子。全盘不自动寻找配对，不按整行滑动，也不在移动后补块。

动作前置条件是局面处于playing、没有其他活动拖拽，且起点存在有效棋子。按下后只创建拖拽预览，原棋盘保持不变；允许拖向任意格，不要求相邻。释放到其他空格时，原棋子身份与等级迁至该格。释放到另一枚同级且等级为1至4的棋子时，重新校验两者身份与占位，一次性消耗两个输入，在目标格生成新身份、等级加一的棋子，源格置空。等级不同、目标五级、自身格或棋盘外释放均不提交。

最小状态包括16格占位、棋子身份与等级、会话内身份序号、局面版本和playing/won/lost阶段；拖拽起点、指针及预览属于临时输入状态。每个身份只占一个格，等级只能为1至5；空格与棋子互斥。一次释放最多提交一次动作，失效身份和重复释放无副作用。以一级为单位的权重为2的等级减一次方，总权重恒为16；移动保持数量，合成数量减一。表现和动画从已提交状态读取，不能反向决定规则。

满盘仍允许同级合成；满盘提示应为“拖动同级棋子合成”，不能直接判负。提交后先检查是否产生五级，有则进入won并锁定棋盘；否则仅在全盘无空格且不存在任何1至4级同级配对时进入lost。任意两格可配对，因此不能只查相邻格。固定开局在正确规则下应可通关，失败边界主要以规则夹具验收。五级不参与合成；胜利后只提供再来一局。

取消拖拽覆盖Escape、pointercancel、失去指针捕获、页面隐藏和窗口改变导致坐标映射失效；全部清除预览且棋盘不变。只接受首个活动指针，其他指针忽略；重开清空输入并更换局面版本，旧回调不能污染新局。本原型不持久化，不写localStorage；刷新、关闭再开均回到固定初局，隐藏期间无离线收益，恢复时展示原已提交局面。

界面上方展示目标“五级”和当前最高等级，中部为正方形4×4棋盘，下方为规则提示及DOM重开按钮；结算层提供结果和再来一局。棋子同时用数字和功能色区分等级，拖拽显示源格与目标反馈。棋盘适配窄屏，按CSS像素测量格位，目标边长至少44像素；画布内部像素与设备像素比映射独立，输入先换算到逻辑坐标。后续提供焦点格、方向键选择及空格拾取/放下、Escape取消，与指针共用规则动作。

## 后续可验收条件（本轮未执行）

- 规则：固定初局16个一级、权重16；完整15次合成后仅余一枚五级并胜利，合成数量按8/4/2/1复算。
- 事务：空格移动保留身份；同级合成在目标格产生新身份；异级、自身、越界、重复释放及过期身份不改状态，失败不先消耗输入。
- 边界夹具：满盘有配对保持playing；满盘无配对且无五级进入lost；出现五级优先won；五级加五级不能合成。不可达边界明确作为隔离规则夹具，不冒充自然游玩结果。
- 输入：真实浏览器鼠标、触控及键盘完成选择、移动、合成、结算、重开；取消、多指、缩放、页面隐藏后无丢子、双提交或卡死。
- 保存：刷新重置；隐藏再返回保留当前内存局面且取消拖拽；不出现恢复旧档或保存成功提示。
- 技术：规则、渲染、输入分离；后续代码与测试阶段真实执行npm run build、npm test、npm run check，check启动实际构建页面交互，记录退出码、浏览器、视口、源码指纹和截图来源。当前无代码，不执行上述命令，不将规范审查称为运行验收。

方法流程为S0确认宿主与zip/流式/动态包形态，S1查落点、元数据与账本，S2确认发现及详情接口契约，S3形成可对账目标集合，S4取得原包、美术与文案，S5编目交付。仅制定方法，不实际连接接口或设备。流式形态没有独立包体时，应明确记为缺上下文，不能将在线入口当原包。接口版与缓存版分别登记，不能假定同版本。

未来采集验收必须具有：宿主和形态命令级证据；原包落盘且逐项对比接口MD5；美术magic bytes与后缀相符；本地索引资源零缺失、文字零乱码；包体及美术清单含ID、名称、来源直链、大小、摘要、分类、开发商；另交付未知清单。索引需可检索并对账文件夹、原包和素材。接口需按实际契约确认分页、返回条数、分批及节流，来源案例建议请求间隔至少1.2秒、约6条一批，不能把案例端点、20条上限或字段名当通用事实。不触碰账号态与支付。

当前缺联网、下载、ADB/root、接口实测与格式检验能力；任务也明确禁止联网、下载和实际采集，因此这些门禁均未执行，不声称采集成功。可采用输入优先级、版本区分、清单和未知项方法，不能复用来源域名、包名、gameId或执行脚本。
