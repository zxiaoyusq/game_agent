# 当前项目离线 AI：真实静态路径与待验证

本章仅分析当前 H5 的 S04，不是 Carrom Disc Pool 原生代码。原路径由 S05 记录为 `development/js/game.js`，_0x50a0ff 约 3485 行、_0x5e7a5f 约 3568 行；完整原文件未在本次包内，行号是定位提示。S04 的 SHA 与读取范围见 [索引](00-阅读索引与证据边界.md)。摘录末尾在 _0x247dad 的 for 初始化中截断，不能执行成完整模块；不宣称已完整解混淆。

## 调度到发射

1. `_0x50a0ff` 重置若干状态、禁用定位控件、设置 striker 视觉与 sensor、播放入场 tween，调用 `_0x338c29(callback, 0x1f4)`。0x1f4=500，但计时包装器未提供，单位和实际等待需核对，不能直接当作测得 500ms。
2. 回调检查 `_0x3fddb3`，按 `_0x5d148e==2` 等条件选择目标集合。集合由 `_0x2a9c75`、`_0x3e4566`、`_0x3231b3` 组合，球色、归属和模式枚举未解码；不将集合名擅自解释为黑/白/Queen。
3. 依次调用 `_0x52106f`、`_0x25af2a`、`_0x521eef`、`_0x30849b`，参数首项为 `_0x2fc10d[0..3]`。用户补充四点关联入袋判定；在已读代码中可直接确认它们用于目标方向与距离计算，不能独立核对其坐标和袋口触发。
4. 汇总候选并 sort；比较器为 `b[_0x157421(0x3f0)]-a[...]`，取第一项，再读取第一项的 `_0x157421(0x32c)`，计算力度 `value/100*60*0.2*1.1*1.25`，即 `value*0.165`。字典未提供，**排序字段及力度来源字段未确认**。候选有 hDot、speed、dist，不代表已证明按 hDot 或距离排序。
5. 无候选调用 `_0x3d12d7()` 并传力度 100。此数是代码参数，单位、上限和实际物理效果未知。
6. `_0xd6b627` 设置 worldY 后进入 `_0x4662ac` 并立即 return。return 后的直接定位/发射代码在此函数当前顺序下不可达，不作为实际执行链。
7. `_0x4662ac` 完成移动后 `_0x223471` 展示瞄准和力度动画，延迟回调再次检查 `_0x3fddb3`，然后 `_0x4b3cc6` 定位、调用 `.test(force, PI-dir+error)`、执行 `_0x24bb4a` 并延迟 `_0xbdafb3`。后两者函数体缺失，不能断言就是停球检测或换手。

## 四组候选几何

四函数结构近似对称：按点与目标球的 x/y 关系筛选，计算目标到目的点的方向及距离，构造距离目标中心约两个半径和的接触点，再枚举 striker 基线位置。候选对象包含 `pos、dir、speed、hDot、dist`。

- 常规基线枚举索引 -1 到 5：-1 尝试目标方向与基线的解析交点，其他为 0/5 至 5/5 的六个位置；会受越界、侧向条件及遮挡过滤，不等于每球必有七候选。找到部分更好候选会提前 break。
- `hDot` 来自方向点积绝对值，递归情形还乘前一方向的一致性；候选仅在超过 `_0x5ccc96` 且超过本球当前最佳值时加入。因此列表更像“逐步改进记录”，不是所有合法解的完整集合。阈值 `_0x5ccc96` 未提供。
- `speed=10+(1-hDot)*_0x301cde`；`dist` 为路径距离之和加递归传入距离。其是否用于最终力度和排序仍取决于未解码字段。
- 当前最佳值 <0.7 时尝试镜像几何的折线路径，枚举 0..3 四个基线位置。前两组使用下方边界镜像，后两组使用右/左边界镜像；边界公式含 26 和 striker 半径变量。可称“单次边框反弹候选几何”，不能称已经通过真实 Planck 轨迹验证。
- 当前最佳值 ≤0.5 且没有累积列表参数时，构造目标球后方约两子半径的虚拟点，再以组合球组递归调用同组函数并传累积列表。结构支持一次额外的组合击球几何搜索候选；内层因已传列表不继续同样递归，不能称无限递归或完整多杆搜索。
- 未见盘面物理前向模拟、数步博弈树或学习模型。完整工程不在，不能据摘录宣称其他算法绝不存在。

## 放置与遮挡

`_0x23a7dc(point,r)` 遍历三组球，中心距离 <r 返回 true。等距接触不在此严格小于条件内，边界是否合理需测试。

`_0x3ea989(start,width,angle,length)` 沿方向每 width 前进一次，共 floor(length/width) 次，调用 `_0x247dad(sample, balls, width*0.9)`。这是离散采样遮挡候选，不是已证明的精确扫掠检测。距离短于 width 时不采样，末段可能未覆盖；但 `_0x247dad` 不完整、球半径和目标排除未知，不能直接认定必然漏检。需对短段、擦边、目标球自身、端点、密集棋子及退化 tan 角做差分测试。

回退 `_0x3d12d7`：优先从 `_0x2a9c75` 随机选目标，空时拼另外两组；随机取合法范围 x、固定基线 y；若重叠，以步进 2 依次向正/负 x 搜索。未找到合法点时仍会返回初始点；所有目标组均空会使所选目标缺失的风险需在运行前置条件中核实，不将风险写成已复现缺陷。
