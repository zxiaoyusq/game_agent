# LUDO 原版美术集成交接

阶段：美术。此文件是设计与资源契约，不是已实现页面或动画。已确认原型、规则核心和上游验收文档保持不变。

## 1. 接入入口与资源分流

- 正式运行图片/音频：`public/assets/visual-manifest.json` 的 `assets` 与 `package_policy.only_assets_allowlist`，共58件（54张PNG、4段MP3）。每件附相对运行路径、SHA256、字节数、实际PNG尺寸、RGBA编码、源ZIP成员/metadata、裁切或整幅策略、trim/offset/originalSize/capInsets。
- 编码：Cocos源文件虽然后缀`.png`，实际为WEBP。全部正式图片以工程图片工具规范为真正RGBA PNG，保留原件，不覆盖源图集。棋盘和骰面精确裁切；native摇骰/HUD/圈/按钮保完整画布，不进行第二次trim。
- 音频为原版逐件imported，57件其他资源中53张图片为原版素材processed，唯一新背景为api-edited。Just Ludo只用于材质/动画研究，本清单未混入Just素材或四头像。
- 所有source路径只用于溯源，不在浏览器fetch，不加载旧商业SDK。构建只复制allowlist及`assets/visual-manifest.json`；不能把`public/assets/`全目录无筛选打包。
- `background-original.png`、`background-api-candidate.webp`仅保留生产证据；`background-purple.webp`、旧native伪PNG、旧dice-roll帧、原图集和全部`reference-assets/`不进最终包。被拒绝的`reference-assets/rejected-background-no-reference.webp`不采用、不作新参考。
- 骰子结果只来自已提交ROLL。中文标签与通用LUDO由Canvas/程序字绘制，不烤进图片。开始与确定按钮底板无文字，关闭/设置用已交付图标；无品牌、广告、金币和商业入口。中文字体使用系统字体，不加载CDN或远端字体。

## 4. 时间演出设计（procedural，不是已运行实现）

摇骰是原版imported帧的时间播放；走子/吃子为原贴图的时间位移；以下闪光和彩纸仅交接Canvas程序化规格，不冒称原帧或AI图片。

- 掷骰默认833.333ms，允许600…900ms；轻微落座弹跳。末骰面严格等于已提交lastEvent.dice，包括无路/第三连6。
- 走子每格110ms（90…130），路径来自提交前后只读进度，营地→0仅一跳。每段`u=elapsed/110`，平面线性插值，竖向附加`-sin(pi*u)*0.30*cellSize`，缩放`1+0.15*sin(pi*u)`；底座阴影仍落在平面路径。落点圈120…180ms渐隐，不能只在落点切帧。
- 吃子碰撞100ms（80…120），逐个capturedIds按提交前progress逆路至0，再回各自营地；每段30ms，末段100ms easeOut。敌叠子可同步回营，全部可见，不更改规则。
- 归家375ms（300…450）：终点半径由0.20格扩到0.55格，白/队色淡光alpha峰值≤0.45，约150…225ms峰值后消退；不覆盖其他色终点。已归家整齐小叠放或计数，保持56位置身份。
- 胜利1000ms（800…1200）：约24枚小矩形彩纸，颜色只取四色与少量白，种子用matchId/revision派生的**独立视觉随机**，不得消费规则rng。初速向外，重力下降、alpha最后300ms衰减；尺寸0.10…0.18格，限制在棋盘与中央结算周边。500ms内可见；结束为Canvas紧凑结算/44px再来一局，不显示商业奖励。
- 当前头像框/合法棋子1400ms克制呼吸（1200…1600），幅度scale≤1.04、alpha0.75…1；不持续大圈转动。“减少动态”关闭呼吸，瞬时对齐同一提交状态，规则/胜者不变。

成功动作同步提交并保存**一次**，再播只读前后快照。busy锁骰子/选子/AI，设置/暂停/重开仍可用。表现rAF用epoch/matchId取消旧局；隐藏/暂停停止动画/音效立即对齐已提交状态，恢复仅调度一次下一步AI。刷新不重发ROLL/MOVE，不存动画坐标/待执行动作。动画end仅解锁，不dispatch第二次。

音效对应roll、step、capture、home，用户首自然交互解锁，设置可静音，音频未解锁或失败不阻断玩法；隐藏/暂停/重开停止。未定位到win精确成员，本阶段**不提供胜利音效**，下游不临时补未经确认资源，可静音胜利并保彩纸。

## 5. 接入后必须真实验收（本阶段未执行）

`design/acceptance.md`不改动，以下为素材接入补充门禁：

1. 最终dist只包含58件allowlist与运行JSON、页面/代码所需相对资源；逐件SHA与art-manifest一致，未知源图/旧格式/拒绝背景/商店板/商业SDK/CDN禁止进入。展开总量严格<10,000,000字节，记录实测值；美术资产约1.11MB不是最终包体通过。
2. Chromium真实访问最终dist，桌面1280×800、手机390×844，补320×568/360×640与DPR1/2。初始菜单/掷骰/点自然合法棋子和44px编号按钮；棋盘营地孔/底座、四色私道和终点、星/箭头、上下头像骰座截图核验。实景中透明十字无黑块/白边，外框仍浅透明，背景不抢棋盘；不能用图像查看器透明RGB误判。
3. 正常速度关闭减少动态：骰子约150/400/650ms至少3个不同spriteFrame/ROI变化；≥3格走子采至少3个格间中间时点，每格90…130ms；吃子碰撞/逆路中间/回营、归家峰值/消退、胜利至少250/650ms两中间帧。真实rAF时间、只读事件、Canvas截图与精灵ROI像素差互证，不能只凭帧名日志通过。
4. 经典/快速×2/3/4席规则与完整对局，真实UI覆盖经典/快速结算、2席人机/4席同屏、3席轮转。固定seed和合法动作指导真实输入，不注入进度/强骰/winner。
5. 动画中≥10次连点、暂停/隐藏/重开/刷新验证revision/rng仅一次，旧epoch不污染新局；音效自然解锁/静音/取消、console/pageerror与资源失败检查。未真机工具，模拟手机Chromium不能称真机通过。
6. 最后源码/资源修改后真实运行`npm run build`、`npm test`、`npm run check`。check启动本地静态服务、访问最终dist并try/finally停止，输出evidence截图/轨迹/ROI数据；check之后不重建或修改dist。代码阶段准备并跑通脚本，测试阶段复核已确认代码；失败返回代码阶段修复重验，不在测试阶段改上游。
