# 代码阶段独立复验的追加问题

首轮代码运行 e891d38f969e4a1eb706e938beb516e3 的 8 项单测和 22 条浏览器检查通过，但独立审查又复现以下两个边界缺陷，因此没有确认进入测试阶段。

1. 360×640 设置面板命中区重叠。声音按钮中心 y=380，高44 CSS；数字辅助中心 y=418.667，高44 CSS。点击声音按钮目标内底部(x=180,y=401)，实际打开数字辅助，sound仍true，symbols false变true。根因是扩展UITransform后未同步调整全部弹窗布局间距。必须检查设置中全部相邻目标、主题选项，以及菜单/关卡弹窗；最小44且不互相抢点击。测试用真实边缘点击确认目标动作，不只测尺寸。
2. 合法截断撤销历史在撤销/刷新后被丢弃。构造现有单测同类的500条合法空管往返链，加载moves=501；真实点击撤销后history=499、moves=500，刷新就被视为坏档，进度和extra丢失。根因是storage.mjs仅以history.length===500判断历史曾被截断；撤销后长度降低但首快照仍是合法中间局。必须持久保留截断状态或可校验边界，并在移动、加管、撤销、恢复、主题切换保持一致；新局重置，不能简单放宽成所有非初始历史均合法。保留未知版本隔离及相邻合法事务验证。补覆盖500→撤销→保存→恢复、多次撤销与继续移动、theme重绘等有效场景及篡改/坏类型拒绝。
