## 范围与证据边界

本轮为 prototype 阶段的只读研究，交付本报告。游戏代码与资源未修改。采用所选竞品分析及 APK 工程分析技能中的证据分层与代码追溯方法。已读取本轮四份冻结品类及 Web 技术资料。

竞品侧依据用户对 MuMu 19.6.0 的单次实测转述。流程为断网冷启动、无网络提示、离线练习、传玩模式。用户记录四项模式 Disc Pool、Freestyle Disc Pool、Carrom、Freestyle Carrom。Disc Pool 初盘18子，界面显示玩家1/玩家2，一杆后0:0且换侧。局内菜单展开后无触控，约6秒采样间隔内观察到母球及高亮玩家由下侧切到上侧。

该记录支持这一次操作中的可观察变化。超时阈值、轮换的完整条件、菜单下变化的内部原因、棋盘旋转及原生实现均待补证。未查看竞品截图、APK或竞品源码，未联网调查。

## 核心循环、规则与物理参数

### 当前代码循环

大厅选模式 → 选桌与扣费保存 → 随机先手展示（教程强制玩家先） → 玩家摆位和拖拽，或AI选点 → 击球运动 → 进袋记录 → 等待静止 → 计分与犯规结算 → 保留回合或换侧 → 胜负结算 → 返回选桌。

上述为H5调用链归纳。竞品完整规则仍以新增观察证据为准。

### 时间与输入窗口

- _0x4bf21a 累加Pixi delta，在 accumulator > 1 时反复调用 _0x49d791(1)。每步 world.step(1/60,10,10)，随后clearForces，定位 [200000,220000)。所读循环无显式最大补步数。
- 玩家可输入条件由教程状态、玩家回合和输入启用共同决定。拖拽距离归一化后力度至少0.25才发射，最大距离取 _0x647bf3=75+25×装备力度等级。滑条将母球横坐标映射到162至483。
- 每杆发射后以2300ms折算的模拟tick延迟进入静止检查，仍运动则每50ms折算tick重试。延迟使用 _0x338c29 与Tweener，随主更新暂停。
- 回合倒计时仅在 _0x3a1262 且桌号非0时递减。基础值为6000、1500、1200、900、600 tick，加装备time等级×2 tick。在60逻辑tick/秒条件下基础值对应100、25、20、15、10秒。0号桌绕过该倒计时分支。
- 普通setTimeout独立于上述暂停，包括匹配展示等路径。需核查旧回调的场景有效性。

### 碰撞、进袋与静止

- 使用Planck零重力世界和四条静态边界，圆形棋子及母球启用bullet。棋子构造 _0x54e9a5 位于 [360000,420000)，母球构造 _0x13fb80 跨 [360000,480000)。
- 棋子半径为16逻辑像素，母球碰撞半径为34×0.8×0.8=21.76逻辑像素，坐标比例100像素/物理单位。棋子配置恢复系数0.45、摩擦0、密度1、线性阻尼1.8。母球配置恢复系数0.5、摩擦0、密度1、线性阻尼2.8。碰撞回调还会调整阻尼，不能把初始参数当作整杆恒定值。
- _0x49d791 依据棋子中心到袋中心距离≤20逻辑像素判进袋，然后移出物理世界并记录结算。进袋判断在本tick物理step之前，存在离散采样边界，需覆盖高速越界。
- _0x56abf7 调用trimVelocity。棋子与母球在 |vx|+|vy|<0.2物理单位/秒时被设为休眠，再用isAwake判断是否继续等待。

### 计分、成功与失败

- Disc Pool与Carrom使用数量分数。_0xbdafb3 在任一侧数量为9时，结合当前回合与中心红子数组是否为空决定 _0x47e567(true/false)。Carrom红子的覆盖、返还和末子次序存在专门状态，验收应覆盖组合边界。
- Freestyle使用类型分值数组[50,20,10]，目标160。结算延迟回调在任一侧达到目标后依据当前回合进入胜负展示。
- 母球进袋置犯规标志 _0x530863。数量模式存在返子与扣分路径，积分模式存在返还本杆棋子路径。
- Freestyle结算出现 playerScore -= 50 / oponentScore -= 50，而主要计分变量使用 _0x4d3bf1 / _0x41f634。同一分支先清 _0x4268e2，后续又检查它，实际可达性及全局绑定尚未动态验证。此项登记为静态疑点，尚无必现缺陷结论。
