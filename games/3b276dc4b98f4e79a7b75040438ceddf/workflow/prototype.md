# Carrom 离线罚棋证据校正审查

## 范围与结论

本轮为 prototype 阶段的只读证据审查，不制作游戏、不修改参考包、不推进美术、代码或测试阶段。仅新增本报告和逐字节提取的研究文本。使用本次修正 brief，不继承其他任务的错误前提。

当前不能从可读原生资料证明离线罚棋的扣分公式、返场棋选择或欠棋策略。操作者观察支持所述三个非零分样例各净减10分，以及其中一次画面黑棋9→10；这与返还既有棋相容，不构成超过初始数量的证据。黑棋单杆入袋+10是独立观察，应保留；视觉图例10/20不能仅按排列配对棋色。联网目标160模式的白棋20→0伴白棋返场，不能直接推广到离线目标180模式。

## 输入与证据等级

- O类：用户转述的操作者录像/画面观察。本轮未收到或观看录像，未由MCP独立验证。
- E类：本轮工具实际读取的ZIP清单、文本、JSON及已有反汇编。已有分析结果是原包衍生资料，不等于本轮重新反汇编原库。
- H类：解释观察的假设，不是已恢复规则。

### 最直接的后续追踪线索

E-06中：

- 第59–60行分别有`GameplayMultiPlayerFreestyleOfflineView.mm`和`GameplayMultiPlayerFreestyleView.mm`来源路径字符串；第79行有`MatchControllerPointDiscPool.mm`。支持分开追踪离线与其他入口，不能直接等同于操作者菜单的运行映射。
- 第2166行`29MatchRefereeShotPointDiscPool`；第2115行`24MatchRefereeShotDiscPool`；第3050–3053、3858–3861行含`MatchRefereeShotDiscPool::process`与`gameplay_referee_animation_outcome_request`的闭包名称。PointDiscPool裁判是计分模式的优先候选，但不可仅凭名称指定为唯一owner。
- 第3042、3850行含`MatchControllerTurnBased::scorePucksForTeam`闭包名称。继续找实际函数体、调用方、team参数及分数写入。不能将排行榜`custom_scoreboards`混作对局计分。
- 第2024、2033行有`puck_potted`、`puck_returned`；第2659–2661、2754–2756行有`TableLogicDelegate::puckPotted/puckPocketed/puckReturned`名称；第5464–5465行有相应carrom.proto名称。适合追踪入袋到返场的事件关系，尚无棋ID与颜色映射。
- 第5680–5681行有`shouldReturnOwedPocketedPucks`与`shouldReturnOwedPottedPucks`。只支持提出欠棋/延迟返还假设，不能证明零分犯规会产生债务，也不能把Pocketed与Potted自行解释成不同处罚。
- 第4746行`effect_foul_reason_striker_pot`支持存在母球入袋犯规提示名称，不给出扣分或返场规则。

推荐证据链：离线入口/模式创建 → 实际裁判对象及process → 母球入袋判定 → 分数写入与返场/欠棋队列 → 停球后提交 → HUD更新。必须用对象身份、分支条件和写入证明链接，而非串联相似名称。当前唯一owner与稳定提交边界均未闭合。

## 可证伪假设

这些模型可组合：扣分公式、返场选择、欠棋、提交时序是不同维度，不应强行选成互斥的一套规则。令S为击球前分数，G为本杆正常入袋所得，P为处罚，则仅观察杆前杆后分差无法单独求出G与P。

|编号|明确假设|与当前观察关系|反证或区分条件|
|---|---|---|---|
|H-01|离线每次母球单独犯规，立即分数为max(0,S−10)，返场另行处理|与O-03/O-05相容；未证明|同一离线版本、无其他得分事件、S≥20时出现净减非10即可反证|
|H-02|处罚为返还一枚本方已得分棋，并从分数撤销该棋实际价值|若返还的是10分黑棋，与O-02/O-03/O-04相容；联网O-06也各自相容|仅持有已确认20分棋时，返还该棋却只减10，则反证严格等值版本；必须控制同杆得分与队伍归属|
|H-03a|混色可返还时，返还最近得分棋|现有样例未约束|保持分数和黑白库存相同，调换最后入袋颜色，返场不随顺序改变可反证严格版本|
|H-03b|返场按固定颜色优先级或棋ID顺序选择|现有样例未约束|相同可返还库存下，单改入袋顺序即改变返场对象，可反证简单固定优先级；空间/ID约束须另控|
|H-04a|零分犯规仅截断为0，不产生待偿还状态|O-05不足以证明|与无犯规对照相比，后续首枚正常入袋被返还、扣抵或不计分，支持反证，但需排除其他规则|
|H-04b|无可返还棋时记录欠棋，未来得分时偿还|E-06含Owed名称，但无行为证明|在已明确债务触发条件和偿还边界后，重复受控实验无差异才能反证该具体版本；仅一次零分不变不够|
|H-05|离线与联网使用不同模式参数或结算分支|目标180/160与样例不同只提供动机|配对版本、同一计分模式及相同已得分棋条件后比较；即使处罚一致也不能证明全部参数一致|
|H-06|同杆得分与犯规有特定先后顺序，且可能延后至停球结算|当前端点分数不能区分|设计普通棋与母球同杆入袋并记录事件顺序、最终分数、返场棋和下一杆状态；需与各自单独事件对照|

不得输出“黑棋20分”“棋数超过12”“罚分不等棋值”作为结论。也不能因黑棋+10观察就未经控制将白棋20视作离线已证规则。

## 最有区分力的实验

全部是待执行方案，本轮没有执行或虚构实验结果。优先级E1→E2→E3，之后再研究同杆时序和跨模式差异。每组保持同一安装构建、离线入口、玩家/队伍与配置状态；每种条件建议至少3次独立有效样本，重复次数不是统计证明。记录完整录像与逐杆表：模式入口、目标、初盘数量、双方分数、黑白在台/已得分数量、入袋颜色和先后、母球事件、返场颜色/ID（可辨时）、杆末和下一杆状态。只在动画结束且分数稳定后记终值；遮挡或有额外入袋的样本标无效，不补猜。

|实验|操作与对照|最有区分力的预期差异|
|---|---|---|
|E1 单色价值校准及处罚|同一离线模式，分别从0开始只正常入袋一枚黑棋、另一新局一枚白棋，确认各自独立得分；再在只有该枚本方已得分棋的条件下让母球单独入袋|若某颜色独立+20，之后单独犯规返该棋且−20，反证恒扣10并支持等值撤销；若返20分棋但仅−10，反证严格等值撤销；只测10分黑棋不能区分两者|
|E2 同库存、互换入袋顺序|A局黑→白，B局白→黑，分数及可返还库存相同，再各做母球单独犯规|返场颜色随最后入袋颜色改变支持最近得分策略；固定颜色支持优先级候选，但仍需进一步区分棋ID、位置、所属权|
|E3 零分欠棋对照|A局0分母球犯规后正常入袋一枚；B局无先前犯规正常入袋同色棋；另设0分连续两次犯规及后续两枚入袋组|后续计分或返场出现按欠债次数累积的差异，区分“仅归零”与债务模型；同时跟踪下一杆，避免错过延迟偿还|
|E4 同杆事件次序|与单独普通棋入袋、单独母球犯规作对照，分别形成普通棋先/母球先入袋的有效样本|比较最终分数、返场对象、是否保留杆权，区分得分前/后处罚及原子结算；不能用动画显示先后代替内部提交顺序|
|E5 无本方可返还棋|对手已有得分、本方0分时本方犯规，并与双方均0分对照|区分可返还棋属于当前玩家、队伍或全局库存；不预设罚棋可从对手取得|
|E6 跨模式配对|分别在离线180和联网160记录完整模式名及单色价值，再执行同样“仅一枚已得分棋+单独母球犯规”|判断差异来自棋值、返场规则还是模式参数；联网20→0单例不得充当离线结果|

如具备后续只读原生分析条件，最优补证不是继续读queenCovered，而是获得PointDiscPool裁判真实方法体、计分写入、返场选择与Owed字段读写的连续调用链，并用E1–E3事件对齐。原库哈希、PT_LOAD、运行maps与模式对象身份必须先配对。

## 当前阶段要求的适用性

本任务是规则证据校正，不是新游戏原型。核心循环仅作为取证模型：记录杆前状态 → 合法击球 → 物理运动与入袋事件 → 犯规/计分/返场候选处理 → 停球后稳定状态 → 下一杆。这个模型不是已证明的内部执行次序。

状态记录应含模式、目标、玩家/队伍、分数、逐色数量、已入袋棋身份、返场事件、可能欠棋、当前杆生命周期。目标180、初盘各12和无红棋按O-01记录为观察基线；达标是否立即胜利、双方同时变化如何结算、犯规是否换手均待证。

物理步长、碰撞几何/系数、停球阈值、输入窗口与力度曲线没有可读证据足以定值，不编造1/60步长或碰撞参数。shotPowerLimits只是配置线索。没有证据定义限时失败、固定单局时长或重开存档语义。

实验误差约定：分数和可见棋数要求整数精确记录，允许误差0；遮挡/动画中计数作为未知，不用误差带补齐。事件时序只报告录像帧分辨率范围，实际帧率未知时不填毫秒精度。物理轨迹容差未测，不声明跨帧率一致。输入仅采用原版界面允许的自然操作，不注入分数或胜利状态。

布局不新设计；取证需同时覆盖原版双方HUD、目标/模式信息、完整棋盘及返场区域。若后续制作实验记录器，可用英文玩家文案`Mode`、`Score Before`、`Score After`、`Returned Disc`、`Shot Complete`，但本轮没有创建该界面或Web工程。
