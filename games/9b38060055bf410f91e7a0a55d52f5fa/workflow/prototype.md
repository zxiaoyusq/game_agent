# Carrom 机器人力度上限补丁静态审查

项目：9b38060055bf410f91e7a0a55d52f5fa。阶段：prototype，仅审查现有补丁与设计取舍，不修改源码、不推进代码或测试阶段。

## 结论与决策

建议保留机器人与玩家正常击球共用的 125 施力幅值上限，同时让候选路线评估感知这一上限。补丁确实限制实际施力，修复了原版预览已经满格、实际仍能超限的不一致；但单独削顶没有证明长路线仍可完成。不能据此判定已经卡局，也不建议无证据恢复 164/165。整体结论：NEEDS_CONTEXT，动态平衡性尚未验收。

用户本机观察玩家上限125、对手曾出现164/165，属于用户观察，不属于本次自行测试结果，也不是竞品规则证据。

## 力度与预览

玩家拖拽距离先限制到_0x647bf3，strength=距离/_0x647bf3；正常strength为0到1，释放需strength>=0.25。传入底层的幅值为strength×100×1.25，正常最大发射125，最低正常发射31.25。装备相关参数_0x647bf3=75+25×_0x2799f0改变满力所需拖拽距离；更正此前说法：已读公式不支持装备提高玩家满力最大值。

B在_0x223471新增Math.min(force,100×1.25)，随后预览和回调共同使用削顶后的局部force。A已有预览strength=force/125并限制显示不超过1，但实际回调仍使用原force。因此B限制的不只是显示。有限正数<=125在这一处不变。

底层[0x1cd]关闭sensor，用force×cos(-angle+π)、force×sin(-angle+π)构造向量，唤醒刚体并调用applyForceToCenter。该方法没有再次钳制或检查有限值。125是传给刚体的力向量幅值，不是直接设置的速度、冲量或进袋距离。物理库内部积分、质量和碰撞仍会影响运动，不能从幅值比例直接推算停距或命中率。

负数与零没有被Math.min设下界；有限性检查也不等于正数检查。正常候选要求dist>=0，正常回退使用100，故不能把内部注入负force的风险说成已发生的正常玩法问题。NaN和正负Infinity在正常发射入口被有限性校验拒绝；若绕过入口直接调用预览或底层，则不能依赖这一保护。

## 候选路径与削顶风险

正常候选请求force=(dist/100)×60×0.2×1.1×1.25=0.165×dist。dist>125/0.165≈757.576时请求值被削顶；此阈值仅是公式交点，不是物理可达距离。

四类候选覆盖直线、碰壁及递归组合碰撞路线，dist累加目标至袋、击球至接触点、反弹分段和递归附加路径。候选虽有speed字段，但正常选球施力使用dist。候选主要按方向匹配hDot、障碍和合法摆位筛选，再按hDot降序取首项。已追踪链路未见按125重新评估能量或可达性、按削顶比降权或重排。

因此存在明确的策略适配风险：仍按原路线选球，却在后段减少其请求力度。长路线、反弹、组合球及残局应重点复核。风险不等于这些路线必然失败；原始力度本身也是启发式，不能假定原版一定命中。

正常链路：新机器人回合_0x50a0ff → 候选与排序 → _0xd6b627 → _0x4662ac摆位动画 → _0x223471误差及预览 → _0x4b3cc6最终校验 → 共用striker底层 → 等静止结算。_0xd6b627在动画调用后立即return，后面的直接施力是不可达代码；game.test开头return之后的示例也不作为正常入口。

## 回退、连续回合和模式

没有几何候选时，_0x3d12d7随机选择目标和合法基线位置，以100请求发射，不受此次125削顶影响。随机点受阻会继续搜索，包含按障碍圆投影查找基线空隙；没有目标或没有合法位置可返回null。

最终发射前如棋盘对象、分组、数量改变，位置移动>1，或摆位越界/重叠，同turn最多回退两次。回退沿用此前force，不按新路径重新估算；B此时沿用的是已经削顶的值。该重试处理发射前局面失效，不处理发射后未进袋，不能作为削顶长路线的补救证据。

无有效回退时通常转玩家，Carrom queen cover待处理及Freestyle queen pending有独立结算分支。turn/round校验、防重复发射标记和重试计数按回合隔离；连续机器人回合重新选候选。已追踪正常链路未见连续空击次数或策略停滞检测。

模式映射已从大厅核实：0 Disc Pool，1 Carrom，2 Freestyle。Freestyle候选目标包含双方普通棋及queen；其他模式按普通棋和queen条件选目标。三模式共用正常预览与击球链路。五桌角度误差触发概率为[0.8,0.7,0.6,0.35,0.2]，误差幅度0.05到0.1弧度且有正负方向；补丁不改变这一随机误差机制。

## 核心循环、规则状态及物理边界

既有循环为摆位→瞄准蓄力或AI选球→发射→碰撞/进袋→等待静止→计分与queen规则→连杆、换人或结局。界面沿用大厅、棋盘、力度预览、底部摆位条及结算界面；本阶段不重新设计布局、不修改玩家文案或资源。

物理步长world.step(1/60,10,10)，随后clearForces；ticker累积后逐逻辑步更新，暂停/广告阻断更新并清累积。棋子与striker均有bullet和allowSleep配置；低速裁剪在|vx|+|vy|<0.2时休眠，属于静止判定，不能解释成最高速度限制。striker线性阻尼2.8、角阻尼5；普通棋线性阻尼1.8、角阻尼0.2。碰撞由现有Box2D世界处理，未进行动态碰撞精度验收。

入袋按逻辑步中心到袋口距离<=20判定。进袋影响计分和连杆，未进袋通常换人，queen cover/归还有独立状态。发射后最初延迟2300ms进入结算检查；物体仍awake则50ms后再查，并非2300ms强制终止物理。因此需区别程序无法结束回合和双方长期不进袋导致残局延长，当前证据只能支持后者存在待验证风险。

输入窗口：玩家在合法操作状态拖拽，释放达到0.25才发射；机器人经过摆位与预览，最终校验通过才发射。已知实现容差包括局面移动>1触发失效、低速和<0.2休眠、袋口<=20。它们是读取到的规则，不等于本次验证过的可接受误差。

## 保留与调整建议

1. 保留125公平上限和预览/实际共用effectiveForce，建议明确区分rawForce、effectiveForce和capRatio，便于定位削顶影响。
2. 在选候选时按实际可用力度评估，优先验证直接短路线；对明显削顶的长反弹/组合路线降低优先级，条件允许时用同一物理模型预测。不要简单把dist>757.576全部删除，因为dist不是能量模型。
3. 回退换路线时重新估算力度，再统一应用上限；没有进袋路线时可考虑合法的推进或解围策略，并以跨回合数据验证效果。
4. 如需通用安全边界，应在真正共用施力入口校验有限且有效的正幅值，再统一限制上限；是否允许零值应明确取消/空击语义，不能只把负数钳成零后仍走正常发射。以上仅设计建议，本次未改代码。

## 同盘面对比与边界验收方案（全部未执行）

固定全部棋子位置、速度、awake状态、striker及fixture参数、装备、桌面、模式、queen状态、随机序列及角度误差，按1/60步长对比A和B。先固定同一候选隔离力度影响，再对比完整策略自然选择。记录候选类型、dist、hDot、rawForce、effectiveForce、预览值、首碰、目标位移、进袋对象、静止停距、回合时长、换人/连杆、连续无进袋回合及整局时长。

盘面覆盖：短直线、dist阈值两侧和等值、长直线、单反弹、多段/组合球、拥堵开球、普通残局、Carrom queen cover、Freestyle queen pending、无几何候选、随机回退、一次及两次发射前重试、回退耗尽、基线完全受阻。五桌和三模式都需覆盖，先关闭角误差隔离变量，再用相同误差序列复核。

幅值边界：负数、0、31.25、100、125±ε、164、165、NaN及±Infinity，分正常入口与内部直接注入两组。候选边界：dist为0/负数/溢出，缺失或无效pos/dir/hDot，基线端点与重叠临界；局面移动为1及1±ε；暂停恢复、广告恢复、重开旧回调、连续机器人回合和重复调用。额外覆盖低速和0.2两侧、袋口中心距20两侧及高速跨袋口。

建议验收条件：正常有效发射幅值不超过125（数值日志比较容差建议1e-9）；预览与effectiveForce/125一致；同回合最多一次真实发射；失效回退有界且能进入正确结算/换人；queen规则无重复计分或遗漏归还。保留原始坐标，不四舍五入后回放。动态轨迹比较应先用同版本重复回放测得数值波动，再确定容差，不能用宽容差掩盖进袋差异。进袋率与残局时长的产品接受阈值需要基于样本及用户目标另定，不伪造通过标准或结果。
