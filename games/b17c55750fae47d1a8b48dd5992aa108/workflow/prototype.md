## 3. 证据分级

## 4. 允许结论与禁止推断

### 允许结论（全部保留摘要前提）

1. 两组同名文件分别存在所报长度及哈希差异，缓存角色文件均较大；完整字节序列不一致。
2. 四个长度均为 16 字节的整数倍。这是总长度性质，不是内部块布局证据。
3. 操作者所做的直接解析尝试没有成功；仅描述这些尝试，不扩大为所有解码器、偏移或格式均失败。
4. 所报 ASCII 检索没有找到四个指定拼写的匹配；不等于没有这些配置语义。
5. 快照只报告一个对象在一个进程、某时点两个偏移的读值；字段名称与语义尚未确认。
6. 静态初始化候选可列作待核对路径，不能视为已执行或最终生效值。
7. 当前证据无法区分默认值、缓存配置、包内配置、其他配置路径、计算或后续覆盖等值来源。

### 禁止推断

| 不得声称 | 原因 |
|---|---|
| “16 字节倍数证明 AES、CBC/ECB、IV、填充或已加密” | 多种序列化、对齐、容器、压缩及填充也可能产生该长度；没有算法、头部或加载器证据 |
| “高熵就能证明加密” | 本轮未测熵；即使测得，压缩与其他二进制数据也可能高熵 |
| “.plist 证明 XML/binary plist”或“解析失败证明不是 plist” | 后缀只是名称；直接解析失败只限定具体方法与入口 |
| “gzip/zlib 失败排除所有压缩” | 未覆盖其他格式、包装、偏移、raw DEFLATE、字典等；不因此建议盲试 |
| “ASCII 没有键名，所以配置没有这些字段” | 可以存在不同编码、数字键、索引、映射或其他表示；这些也只是可能性，不是已确认编码 |
| “缓存更大/哈希不同说明热更新、服务端下发、篡改、损坏或字段更多” | 字节差异不提供生产机制、语义或完整性判定 |
| “原包对应同一版本/签名/ABI，缓存一定更新” | 摘要未配对构建与时间谱系 |
| “文件存在即被加载，打开即解析成功，解析成功即被采用” | 各环节是独立命题，需要独立证据 |
| “+0x30 就是 minPower、+0x28 就是 maxPower” | 对象身份、布局、类型和使用点未配对；偏移不是字段名 |
| “20/235 是全局最小/最大力度、物理单位或缓存中的值” | 单对象快照不能证明字段语义、适用范围或来源 |
| “静态候选常量等于运行值，所以来源已证明” | 数值相等不构成因果链，分支、初始化、覆盖及对象身份均未闭合 |
| “允许操作者只读观察就意味着本代理已拥有设备或文件访问能力” | 用户任务限制与当前实际工具能力都不支持这种声明 |

不存在证据不足时的编码或来源“最可能结论”。上述候选不按概率排序，也不虚构置信度。

### 5.2 步骤 A：固定身份、长度与字节比较

操作者可在已有 Python 3 的离线主机使用下面的标准库片段；无需安装依赖。参数顺序固定为缓存 GameConfiguration、原包 GameConfiguration、缓存 ValueMap、原包 ValueMap。尖括号参数应替换成已有副本的真实路径，不猜路径。本代理不运行此命令，也不承诺当前执行器支持 Python。

```bash
python3 - '<缓存GC副本>' '<原包GC副本>' '<缓存VM副本>' '<原包VM副本>' <<'PY'
import hashlib
import json
import os
import sys

expected = [
    (1418432, 'b8d7202858216fdf0c90eb8ed006508e9614a57ffe0322dec5f8db58eb0d299e'),
    (1241984, '8ac8ad337c3c2f89812aa44f22a4bf01c09d05e2e8459d2e18918398592621f6'),
    (119552, '90f153c103a2b3bd54bbb2ef316d8ad444efa1e78af1f9a622d0cf97254ae667'),
    (110368, 'cfaf3df66677a1b0aa9c1831b7e0f3ab5cf4fdb841ad266bd8e58660f0a89f62'),
]
labels = ['cache_gc', 'package_gc', 'cache_vm', 'package_vm']
needles = [b'minPower', b'maxPower', b'extraMaxPower', b'strikerProperties']
if len(sys.argv) != 5:
    raise SystemExit('需要按固定顺序给出四份授权离线副本')

def signature(stat):
    return (stat.st_dev, stat.st_ino, stat.st_size, stat.st_mtime_ns)

buffers = []
for index, path in enumerate(sys.argv[1:]):
    with open(path, 'rb') as stream:
        before = os.fstat(stream.fileno())
        data = stream.read()
        after = os.fstat(stream.fileno())
        stream.seek(0)
        repeat_hash = hashlib.file_digest(stream, 'sha256').hexdigest() if sys.version_info >= (3, 11) else hashlib.sha256(stream.read()).hexdigest()
        final_stat = os.fstat(stream.fileno())
    digest = hashlib.sha256(data).hexdigest()
    if signature(before) != signature(after) or signature(after) != signature(final_stat) or digest != repeat_hash:
        raise SystemExit('输入读取期间不稳定，停止比较')
    matched = (len(data), digest) == expected[index]
    print(json.dumps({
        'label': labels[index], 'size': len(data), 'sha256': digest,
        'matches_summary': matched, 'remainder_mod_16': len(data) % 16,
        'ascii_exact_case_sensitive_counts': {n.decode('ascii'): data.count(n) for n in needles},
        'offset_zero_signatures': {
            'binary_plist': data.startswith(b'bplist00'),
            'gzip': data.startswith(b'\x1f\x8b'),
        },
    }, ensure_ascii=False))
    if not matched:
        raise SystemExit('副本与所报摘要不匹配，不沿用本次比较身份')
    buffers.append(data)

for left, right in [(0, 1), (2, 3)]:
    cache, package = buffers[left], buffers[right]
    overlap = min(len(cache), len(package))
    same = sum(a == b for a, b in zip(cache, package))
    prefix = 0
    while prefix < overlap and cache[prefix] == package[prefix]:
        prefix += 1
    suffix = 0
    while suffix < overlap - prefix and cache[-1-suffix] == package[-1-suffix]:
        suffix += 1
    print(json.dumps({
        'pair': [labels[left], labels[right]],
        'size_delta_cache_minus_package': len(cache) - len(package),
        'growth_percent_package_denominator': (len(cache)-len(package))*100/len(package),
        'same_offset_equal_bytes': same,
        'overlap_bytes': overlap,
        'same_offset_different_bytes': overlap-same,
        'unpaired_tail_bytes': abs(len(cache)-len(package)),
        'common_prefix_bytes': prefix,
        'nonoverlapping_common_suffix_bytes': suffix,
    }, ensure_ascii=False))
PY
```

输出不包含文件原始字节、字段值或真实路径。SHA-256 采用完整文件；搜索固定为全字节缓冲区、ASCII、区分大小写、精确拼写；Python bytes.count 是非重叠计数。哈希成功不等于格式或配置身份确认。

字节比较采用“相同文件偏移”口径。中间插入会使之后大量偏移错位；相同偏移差异数不等于实际编辑量。首尾相同片段只报告字节边界，不称为 IV、头部、记录区或认证标签。零偏移签名匹配只是格式候选，不等于完整解析成功；签名不匹配也不排除包装内存在该格式。片段只提供复现方案，不是经过运行验收的交付脚本。

### 5.3 步骤 B：约束格式复核，而非盲目解码

1. 对 A 中身份匹配的四份副本采用同工具、同版本、同参数、从 offset=0 开始的检查，不能只检缓存后把结论套到原包。
2. 先对照已授权加载器或明确格式文档。仅按证据支持的入口尝试 plistlib.load、gzip 或 zlib；记录实际工具版本、调用参数、错误类型、成功消耗字节数和尾随数据处理。输出只保留格式结果，不输出解析后的字段内容。摘要原先未给出的参数不能由本代理补写成“当时已用”。
3. 如需尝试解压，限定输出上限与耗时，内存中处理，不落地展开内容；达到上限记为“限额停止”，不误标为格式无效。未经证明不偏移穷举、递归全格式扫描或尝试密钥。
4. 若加载器显示需要受限制的密钥、账号态或额外权限，停止格式复核并保留未知。不能以“可复现”之名调用目标游戏解密或触发其执行。
5. 可选的熵/重复块统计只作为字节分布描述，不作为算法判断；本次没有必要以此扩大范围。

### 5.4 步骤 C：只读静态配对与数据流候选

仅对已有授权构建和分析导出进行离线阅读，不执行目标代码：

- 先登记构建哈希、模块哈希、ABI、符号/布局资料身份，核对它们是否与 E-07 快照的构建匹配；无法配对则停止偏移映射。
- 跟踪文件路径选择与优先级（包内、缓存、回退），读取结果、格式转换、查找键/映射、初始化、字段赋值与后续覆盖。记录分支条件，不以字符串交叉引用替代执行证明。
- 为对象类型、+0x30/+0x28 的类型/宽度/语义寻找匹配布局证据，并检查字段读取使用点；静态名字相似或初始化常量相同不够。
- 建立“候选路径/输入来源/赋值目标/分支/可能覆盖/证据位置”表。结果最多称为静态数据流候选，不声称本次运行采用该路径。

### 5.5 步骤 D：来源闭环的只读门槛与当前上限

在不修改设备和游戏的约束下，只能优先复核操作者已经合法取得、可脱敏的现成日志或快照。如果它们没有覆盖下列链条，来源继续未知；本轮不要求产生或提交这些材料，不将启用追踪、附加调试器或启动游戏列为动作。

来源成立需要同时证明：

1. 对应构建和时点选择的是哪一份文件；以与摘要匹配的内容身份绑定，而不只给路径。
2. 实际读取成功及字节范围；“打开”不足以证明完整读取。
3. 实际解析成功并选择目标配置项；“读取”不足以证明解析采用。
4. 字段值到匹配对象偏移的实际赋值；值相同不足以证明来自该文件。
5. 在声明的生效时点前，没有回退、重算或覆盖；结论限定进程、对象、时点与所覆盖路径。

现成记录不足时，D 保持 BLOCKED。本计划可以复现静态差异与检查口径，不能保证在严格不产生新运行证据的约束下证明缓存加载或字段来源。
