## 续接验收顺序（未执行）

### 1. 重组身份门禁

在具备只读离线执行能力的环境，依 E-01 的精确 member 逐件读取，先复算每块尺寸和 SHA，再按 E-02 数组顺序串联。重组文件尺寸必须为 48,998,992；复算 SHA256 必须严格等于目标值。任一不符立即停止地址分析，不调序猜测。保留工具版本、命令、退出码、完整输出及重组文件哈希。

随后读取 ELF magic、class、endianness、e_machine、e_type、program headers、动态符号及重定位。文件名 arm64 不是 EM_AARCH64 的证明；具体库名、构建版本、是否剥离符号目前未知。

### 2. 地址模型

对落在 PT_LOAD 文件覆盖区间的偏移 F：`link_va = p_vaddr + F - p_offset`，必须同时满足 `p_offset <= F < p_offset + p_filesz`。BSS 只存在于内存部分时不得给出文件偏移。每条地址记录整文件 SHA、模块身份、AArch64 架构、地址类型、段映射和原始字节证据；函数入口、调用点、字符串地址、对象字段偏移分别列项。

运行时使用 `runtime_va = load_bias + link_va`，load_bias 需从匹配文件偏移的实际映射及页对齐求证，不能直接使用首个可执行 mapping 起点。本轮没有 runtime_va。

### 3. 有界字符串与数据流追踪

先全文件按字节查找所有 `StrikerStatsNode` 和 `power:aim:time:` 命中，记录精确偏移、终止符和边界字节，跨分块字符串必须用重组文件处理。Force、power、装备 ID 等只作扩展线索，字符串邻近关系不作为数据流边。

对每个命中解析重定位/指针引用及 AArch64 ADRP+ADD、ADRP+LDR 等引用序列；指令窗口按 4 字节对齐且位于可执行段。首轮每个候选函数最多查看 256 条指令、上游下游各最多两层，每一轮扩大均记录具体原因。边界只是研究预算，不能据线性窗口武断认定函数边界或“没有调用者”。间接调用、虚表、尾调用、内联与跨基本块地址构造单独登记。

待证明的链路分四段：
1. 装备数据来源/解码 → Force 对应字段写入：证明键或索引、对象身份、写入指令、字段类型及范围。
2. 装备选择 → 保存/恢复 → 当前对局应用：区分只保存装备 ID、保存属性副本及仅更新 UI；证明应用时机和所有分支条件。
3. 当前属性读取 → 用户拉杆/输入归一化 → 实际输出量：逐条跟踪标量、向量、限幅、换算及调用约定，不能从 UI getter 推出物理消费。
4. 输出量 → 真正物理接收端：确认是冲量、持续力、速度设定或自定义积分状态写入。只有库导入名或可达调用边不够，必须核对调用实参来源与执行分支。

每条候选边附 caller/callsite/callee 的 link_va 与 file_offset、原始机器码、寄存器或栈参数、分支条件、读写对象身份及未解析间接边。链闭合前结论不得超过“静态关联”。目前上述四段均未定位，不提供伪地址或伪公式。

### 4. 受控运行实验设计

此段是后续可复现实验方案，不是执行结果。继续遵守不修改游戏、不联网；优先原版已有的离线练习模式。若原版无法离线进入同一局面，则动态阶段 BLOCKED，不自行联网解锁。原生调试/只读采样另需用户授权与真实运行环境，当前不存在 ADB/调试器通道。

- 固定版本/ABI/已加载库 SHA、局面、发射位置、方向、归一化拉杆距离和输入序列；记录输入提交时间与物理 tick。选择仅 Force 不同而其他可观测属性相同的装备；做不到则标明混杂，不能归因于 Force。
- A/B/A 顺序重复同一输入，观察已确认的属性写入/应用字段及物理接收端参数、首个无碰撞步的速度；读取参数不主动调用未知签名函数，不改内存或补丁游戏。
- 在相同装备下选至少三个输入档位，比较是否饱和、非线性或按不同路径输出；装备差异和输入差异分别取证。
- 先测无碰撞发射，避免质量、摩擦、反弹与进球结果掩盖初始量；再单独观察首次碰撞。球跑得更远不能独立证明施加力更大。
- 换装后对比即时 UI、对局初始化时字段应用、正常退出再冷启动恢复；不臆定属性值直接持久化，允许只存 ID 并重新查表。
- 物理步长、补步、输入窗口、碰撞参数、计分及胜败规则均从目标运行/代码取证，当前未知，不以原型默认值填充。计分或胜败不是 Force 链验收替代物。
- 可接受误差：哈希、指令字节、地址换算和整数 ID 必须精确一致；原始浮点位模式先如实记录。轨迹误差在同装备同输入基线重复采样后预登记阈值，区分 tick 对齐误差与测量误差，不擅自设定竞品物理常数或误差范围。若输入不能达到同样归一化值，报告实际差异，不能用任意容差掩盖。
