## 3. 审查模型与不变量

令 H=`hostPaused`；T=有效广告令牌集合（实际存储为数组，其唯一性尚待核验）；N=`adTokens.length`；B=`H || N>0`。P=当前局/回合阶段；G=局/场景代次；I=瞄准/滑条/指针会话；R=计时记录及剩余时间。

这里的“可运行”指**没有宿主/广告阻塞**，不是自动获得回合行动权。玩家输入还须满足 P 允许、当前玩家、未结算、会话未失效等游戏条件。若还存在玩家菜单暂停、页面不可见、场景销毁等条件，必须独立合并或在各消费者中明确处理；E-01 没有证明 B 包含这些条件。

建议验收不变量（不是已确认实现）：

- B=true 时不接受新的出杆、移动击球器或回合/结算提交；允许纯显示重绘。广告网络回调、广告看门狗等控制调度不能随 matchTimers 一起停到无法解锁。
- B=true 时比赛计时、AI 行动和物理步进冻结；已进入调用栈的同步物理步骤以明确原子边界完成，不要求中断半个求解步骤。
- 从 B=false 到 true 取消当前 I；暂停后的旧 release/move 不提交动作。恢复后须新的合法 down，不能恢复蓄力并自动出杆。
- 从 B=true 到 false 才允许重新挂载有效 R；每条计时记录最多一个活动句柄。重复 resume、重复广告完成不得扩增活动句柄、重置剩余时间或重复领奖。
- 移除一个令牌不代表所有广告结束；未知/重复/旧代令牌不得移除其他请求或解除 H。广告失败也必须关闭自身令牌，而不是全局清空。
- 已结束/销毁局面的旧回调不作用于新 G；奖励依据自身结果和幂等键提交，不把“解除暂停”当作“广告奖励成功”。
- 静音是多个来源的合并，恢复宿主不覆盖用户关闭音频或其他仍存在的静音来源。
- 输入可用性是派生状态。canvas 样式只是浏览器命中层，不是业务权限；键盘、document/window 监听、捕获/已排队事件与程序调用仍需独立验证。

## 5. 恢复顺序与可达路径

1. **宿主先恢复：** S0 → pause → SH → adPause(a) → SHA → resume → SA → adResume(a) → S0。SHA→SA 中 B 未下降，但恢复函数被调用、canvas 样式被还原。若恢复函数内部无保护，计时可能先运行；若输入 handler 只查 H 或只靠样式，广告期间可能出杆；若最后 adResume 再挂同一记录，可能双句柄。当前只能证明调用差异，不能证明这些后果。
2. **广告先结束：** S0 → adPause(a) → SA → pause → SHA → adResume(a) → SH → resume → S0。E-01 的 adResume guard 保证 SHA→SH 不主动调用计时恢复；仍不能替广告输入/静音/遮罩恢复代码背书。
3. **两令牌乱序：** SHAM(H=1,T={a,b}) → resume → SAM → adResume(b) → SA → adResume(a) → S0。只有最后一步允许恢复。交换 a、b 应产生相同宿主/广告层终态；奖励结果不能因完成顺序被串给另一请求。
4. **重复完成：** T={a,b} → adResume(a) → T={b} → adResume(a)。第二次应无影响；实际删除算法缺失，不能确认多令牌安全。
5. **中途重开/场景切换：** 广告请求属于 G1 → 切到 G2 → 收到 G1 的完成。新局不得被旧计时/奖励改变；旧令牌如何完成自身清理取决于广告 owner 是否跨场景，不能简单规定“全部忽略”而留下永久阻塞。

JavaScript 单线程减少同时写变量的竞争，但不能消除同步 SDK 回调重入、外部事件排队、微任务、已到期 timer、旧局回调或异常造成的部分提交。状态表应在每个外部可观察边界检查，不只检查最终 H/N。

## 7. 输入、物理、碰撞、计分与界面验收定义

本轮不设计新玩法或改变现有规则。核心循环仅作暂停插入点：观察棋盘 → 合法回合放置/瞄准/蓄力 → 出杆 → 物理运动/碰撞与入袋 → 稳定边界计分/回合或胜负结算 → 下一回合/重试。当前局的模式、完整计分/犯规/胜负公式未知，不以历史数值补齐。

| 项目 | 本轮建议的边界规范 | 现版事实缺口 |
|---|---|---|
| 输入窗口 | B=false且现有P允许时接受新的down；到出杆提交再查B/P/G/会话。B上升即取消手势；暂停后只允许新的合法down，不延迟回放暂停中输入 | 实際输入handler及提交函数缺失；不规定新的力度或时限 |
| 物理步长 | 使用现版已确认的固定步长h作基线；B=true不新增求解步。最终解锁时更新时钟基准，首帧仅消费恢复后时间，不消费暂停墙钟；补步上限K须从现版读取 | h、K、ticker/tween更新规则均未知；本轮不编造1/60等现版参数 |
