## 2. 定位、核心循环与首版范围

一句话：观察下一块和落点，移动/旋转动物四连方块，选择降落位置，锁定后清除满行获得分数，以逐渐加快的自然下落挑战最高分。

局内循环：生成 → 自然下落/移动/旋转/降落 → 接地锁定 → 满行判定及短动画 → 压缩棋盘、计分、升级 → 生成下一块。触顶结束后展示本局成绩，允许再玩一局。

跨局循环：最高分本地保存；无货币、解锁、付费、排行榜或关卡胜利。成功反馈为消行、升级和刷新纪录；一局唯一终止结果为触顶结束，没有通关目标、倒计时或步数限制。体验假设：初学者首局约 2–8 分钟，不是硬性时限，代码试玩后按实际难度评估。

首版包含：10×20 可见棋盘、七种四连方块、七袋随机、顺时针旋转及 SRS 踢墙、软降/硬降、锁定延迟、同时消行、分数/行数/等级/最高分、下一块一枚、落点虚影、开始/暂停/继续/重开、手机按键、后台自动暂停、最高分持久化。

首版不包含：暂存方块、180°旋转、逆时针专用按钮、T-spin/连击/背靠背加成、联网、音效资源、拖动棋盘手势、跨刷新整局恢复、自动离线推进。刷新回到待开始，仅保留最高分；“恢复”指当前页面暂停/后台返回后继续，不暗含整局存档。

## 3. 棋盘、方块与随机契约

- 坐标：x=0…9；可见 y=0…19；另设隐藏缓冲 y=-2、-1。占格整数坐标，空格为 null；固化格仅存类型。越左右/底部/隐藏顶边均非法。
- 类型与出生态：I=`..../IIII/..../....`；O=`.OO./.OO./..../....`；T=`.T./TTT/...`；J=`J../JJJ/...`；L=`..L/LLL/...`；S=`.SS/SS./...`；Z=`ZZ./.ZZ/...`。斜杠为矩阵换行，点为空。
- 矩阵出生左上角 x=3、y=-2；I 使用 4×4，O 使用固定 4×4，其他使用 3×3。出生方向为 0。隐藏期间照常下落；出生重叠则立即结束。
- 每个七袋含 I/O/T/J/L/S/Z 各一次，Fisher–Yates 洗牌；用可注入随机源/种子支持测试，正常局不用固定序列。预览从同一队列读取，不另抽随机。每次取块确保至少剩一枚预览。
- 顺时针方向 0→R→2→L→0；JLSTZ 绕 3×3 中心，I 绕 4×4 中心，O 不变且不重置锁定时间。不得因为旋转改变类型或动物。
- 踢墙采用以下确定性 SRS 顺时针测试表；本表已转为屏幕坐标（向下为 +y），按顺序尝试，首个合法位移提交，全部失败则完全不改变状态：

| 方向 | JLSTZ 的 (dx,dy) 候选 | I 的 (dx,dy) 候选 |
| --- | --- | --- |
| 0→R | (0,0),(-1,0),(-1,-1),(0,2),(-1,2) | (0,0),(-2,0),(1,0),(-2,1),(1,-2) |
| R→2 | (0,0),(1,0),(1,1),(0,-2),(1,-2) | (0,0),(-1,0),(2,0),(-1,-2),(2,1) |
| 2→L | (0,0),(1,0),(1,-1),(0,2),(1,2) | (0,0),(2,0),(-1,0),(2,-1),(-1,2) |
| L→0 | (0,0),(-1,0),(-1,1),(0,-2),(-1,-2) | (0,0),(1,0),(-2,0),(1,2),(-2,-1) |

## 4. 时序、锁定与计分

- 初始等级 1、分数 0、行数 0；自然下落间隔 `max(100, round(1000 * 0.8^(level-1)))` 毫秒。每次自然下降一格；每次生成或合法移动/旋转/下降后立即检查下方一格是否合法，不合法即进入接地锁定等待，不额外等待下一次重力节拍。
- 软降按住：间隔 `min(50, gravityInterval)` 毫秒，每成功下降一格 +1；软降替代而非叠加自然下落。碰地不强制立即锁定。
- 硬降：移动到最大合法 y，距离 d 加 `2*d`，立即且仅锁定一次；距离 0 也锁定、降落分为 0。同一帧旧方块的剩余输入作废，不能穿透到新块。
- 首次接地启动 500ms 锁定延迟；成功水平移动或有效旋转且操作前/后接地时可重置，单块最多 15 次，失败动作与 O 旋转不重置。离地时停止累计接地时间、不清除重置计数；重新接地继续剩余延迟，未耗尽重置额度的有效操作可重置。达到上限后不能无限拖延；硬降绕过延迟。
- 锁定顺序：把当前四格写入棋盘 → 找出可见区所有满行 → 一次提交消行奖励/累计行数/新等级 → 有满行进入 180ms 消行动画（输入冻结）→ 同时删除满行并整体下压（隐藏区格可随之落入可见区）→ 检查隐藏区残留 → 取下一块、检查出生碰撞。无满行跳过动画立即继续。动画期间不存在新的可操作块。
- 若清除压缩后 y<0 仍有固化格，或新方块出生占格重叠，则结束。不能因活动块尚在隐藏区、尚未锁定就错误结束。
- 一次清除 1/2/3/4 行分别 +100/300/500/800 × **锁定前等级**；0 行 +0；新等级 `1 + floor(totalLines/10)`。降落分不乘等级；不加其他隐含奖金。
- 示例：等级1、累计9行，双消加300分，累计11行，等级变2，随后间隔800ms；等级2四消加1600。清行动画或暂停不得重复结算。
- 时间推进与渲染分离；后台不可补算。恢复重置帧基准，单帧有效 delta 上限100ms，避免切标签或长帧瞬间坠落。暂停保留当前块、重力余量、接地时间、动画剩余时间和随机队列。

## 5. 状态、动作与不变量

状态数据：`phase`、22行棋盘、活动块（类型/方向/x/y）、队列与随机源状态、score、totalLines、level、bestScore、gravityElapsed、lockElapsed、lockResetCount、clearRows、clearRemaining、pausedFrom、sessionId。渲染插值与粒子不作为规则事实；资源错误和存储错误为独立 UI 状态。

| 状态 | 合法动作与转移 |
| --- | --- |
| 加载中 loading | 加载本地资源；成功→ready；失败→error，显示重试，不显示空白可玩棋盘 |
| 资源错误 error | “重新加载”；不接受玩法输入 |
| 待开始 ready | “开始游戏”→falling，重置局内数据、不清除最高分 |
| 下落 falling | 左右/旋转/软降；接地→grounded；硬降→锁定流程；暂停→paused |
| 接地 grounded | 左右/旋转可能离地→falling；计时到期或硬降→锁定流程；暂停→paused |
| 消行 clearing | 冻结移动/旋转/降落；允许暂停；动画完成→压缩/触顶检查/下一块 |
| 暂停 paused | “继续游戏”→pausedFrom；“重新开始”清局→falling；所有降落与锁定时钟冻结 |
| 结束 gameOver | 展示成绩；“再玩一局”→新局 falling；降落/移动输入无效 |

- P 仅在活跃局与暂停间切换；首屏/结束不隐式开始。页面隐藏自动暂停，返回仍停在暂停，需明确继续。
- 活跃局按“重新开始”先自动暂停并显示“重新开始会清空本局进度。”，按钮“取消”“重新开始”；取消返回原活动子状态。结束后的再玩不弹确认。
- 无效移动不扣分、不改棋盘；固化格不相互重叠；活动块恰有4格且不覆盖固化格；满行同批删除不漏行；分数非负且在本局不下降；level与累计行数一致。
- 一次动作提交一次；重开递增 sessionId，旧动画回调、按键重复和异步资源结果不影响新局。暂停/重开/失焦释放长按，恢复不得粘键。
- 最高分为所有已获得分数的最大值，分数刷新纪录时及结束时尝试持久化。保存 JSON `{version:1,bestScore:非负安全整数}`；非法/损坏记录回退0不崩溃；未知版本忽略并提示。读写失败显示持续可见“最高分暂未保存，仅本次有效”，保留内存最高分，只有实际写入成功才清除。file:// 的浏览器存储可能受限，不以存档失败阻断玩法。

## 6. 输入与中文界面

桌面：←/→左右移动，↑顺时针旋转，↓软降，空格硬降，P暂停/继续。方向键和空格在游戏操作上下文阻止滚页；旋转/硬降/P不接受系统 key-repeat。左右首次立即移动，持续按住150ms后每60ms重复；相反方向以最后按下者优先，释放后仍按住的方向恢复。常规 DOM 按钮仍支持 Tab、Enter/Space，不拦截聚焦按钮的原生激活事件。

手机及鼠标屏幕按钮：“左移”“右移”“旋转”“软降”“硬降”；左/右/软降长按，其余一次按压一次动作。使用 Pointer Events/capture，pointerup/cancel/失焦释放；不同时叠加 touch 与 click 两套触发。每个动作按钮绑定单个指针，可另一指针旋转/降落；左右冲突规则同键盘。多指硬降仍只提交一块的锁定。按钮区域禁浏览器长按选中和手势，页面其他区域保留正常滚动。不靠棋盘拖动操作。

中文文案：
- 标题“萌兽方块”；HUD“分数”“最高分”“等级”“已消行”“下一块”。
- 首屏“移动、旋转动物方块，填满一整行即可消除。堆到顶部时游戏结束。”
- 桌面操作行“← → 移动 · ↑ 旋转 · ↓ 软降 · 空格 硬降 · P 暂停”；手机“按住左右移动或软降，点击旋转与硬降。”
- “开始游戏”“暂停”“继续游戏”“重新开始”“再玩一局”。暂停层“游戏已暂停”；结束层“游戏结束”“本局分数”“刷新最高分！”（仅本局实际刷新时）。
- 加载“正在准备动物方块…”；错误“资源加载失败，请重试。”“重新加载”。
- Canvas aria-label：“俄罗斯方块棋盘，10列20行”；所有图标按钮提供对应中文名称。DOM承担关键文案和按钮语义，结算/暂停适度使用 live region，不逐帧朗读。
