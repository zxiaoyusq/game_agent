## 2. 体验目标与首版范围

以十字棋盘为主画面，保留原版紫色纹理背景、四色营地、奶油白格、亮面棋子、白灰立体骰子及头像/必要音效。局内注意力顺序：当前玩家与骰子→合法棋子→落点/安全星→门状态→归家与结算。不是仪表盘或卡片式网页，不生成AI整屏替代原图，不用商店缩略图代替运行棋盘。

核心循环：选择模式与席位→随机确定首位→当前玩家摇骰→亮起合法棋子→玩家或AI选一枚→逐格移动→处理安全/吃子/开门/归家→检查胜利→奖励一次再掷或顺序换席→直到胜利→庆祝与结算→同配置重开或回菜单。

首版包含：
- 经典、快速；2～4个有效席位，每席4子；允许每席设真人、AI或空席，至少2有效席且至少1真人；全真人同屏及混合人机均可。
- 2席默认对角0/2，3席默认0/1/2，4席全开；用户可换空席；地图永远保留四营地，空席不生成棋子且跳过轮转。
- 开始/继续、模式选择、席位配置、头像选择、简明规则、音效/音乐设置、重开确认、回菜单确认、阶段完整存档与刷新恢复。
- 输入同时支持鼠标与触摸；320/390px手机和桌面；同一局不中途改模式/席位。AI给出短思考提示，不抢真人输入。
- 全模式统一首名结束，结算只宣布赢家，不捏造其余玩家名次。

排除：联网房间/匹配、账号、排行榜经济、广告/内购、Luck/皮肤数值buff、新手操控点数、皮肤商城、Bomb/Roadblock/Rocket道具模式、撤销、复杂物理及原生APK。头像与配色用于辨认，不影响随机概率。

### 3.2 精确棋盘与路线

玩家索引：0左下蓝、1左上红、2右上绿、3右下黄。功能色首版固定，避免皮肤旋转造成色/路径误配。

总76格：外环绝对格0～51，四队归家道52～75各6格。设p∈[0,3]、s=13p：
- 起点`s`；锁门普通路线`normal[p][k]=(s+k)%52`，k=0…51，共52位置循环。
- 归家路线`terminal[p]=[(s+k)%52,k=0…50] + [52+6p,…57+6p]`，共57位置；起点进度0，门前进度50，第一归家格进度51，逻辑终点进度56。
- 四队门前分别50/11/24/37；下步分别52/58/64/70，而非51/12/25/38。
- 逻辑终点57/63/69/75。营地→起点不是这56步中的6步；从起点到终点需56个步进。
- 安全格恰好`[0,13,26,39,8,21,34,47]`，包括四起点和四星格；不是所有色格都安全。归家道为本席专用，不允许敌子进入。
- 原场景每格38×38，局部中心见board-contract；保留不完全等距坐标，逻辑绝对格与屏幕坐标分离。

### 3.3 合法走法及快速门

骰子独立、公平均匀1～6，摇骰开始即确定并持久化结果，动画只展示、不修改结果。首位从有效席均匀随机；之后按索引升序循环并跳空席。

棋子状态`base | ring | homeLane | finished`，除逻辑状态外保存绝对格或归家进度。合法动作必须由纯规则函数生成，真人与AI共用：
1. `base`仅6合法；动作是出营到起点，消耗本次骰子，不再走6格。起点安全，已有棋子也允许叠入。
2. `finished`永久无动作，不能再次获归家奖励或被吃。
3. 经典`ring/homeLane`按terminal前进d步，d不大于到进度56的剩余步数；超点整次不合法，不反弹、不停在终点、不拆给多枚棋子。
4. 快速开局每有效席棋子0/1处起点，其余2/3在营地；该席`homeUnlocked=false`。锁门时外环每步按normal循环，归家道不能进，不接受“绕一圈自动解锁”。
5. 快速在非安全格成功吃子，永久令行动席`homeUnlocked=true`；队伍其余棋子同时获门权限，但当前位置不变。被吃、回营、再出营不重新锁门；其他席门不受影响。
6. 开门后，每个外环棋子每步：若当前格为本席门前，下一步转第一归家格；否则外环+1 mod52。进入归家道后只按本席道前进，须精确终点。
7. **normal最后格边界**：0席51、1席12、2席25、3席38开门时仍合法保留该格；下步到本席起点，再沿环走到下一次门前才进道。不将它映射为terminal[-1]、不瞬移到门/终点。可计算专用remainingDistance或逐步枚举，不能仅对terminal.indexOf结果作剩余步判断。例：蓝子停51，另一蓝子吃子开门，下一次掷1，该子51→0；到蓝终点剩余57步。
8. 没有合法棋子：短提示“无可移动棋子”后结算轮转；骰子6仍保留一次再掷，非6换下席。不重复摇骰以寻找能走的点。
9. 唯一合法棋子也要求真人点击，便于输入/动画验收；AI在合法集合中选一枚，不越权替真人操作。

### 3.4 吃子、叠子、奖励和胜利

移动穿过任何叠子不阻挡，不沿途吃子；只在最终落点判断一次，先读取移动前占用：
- 安全格：任何数量/颜色都免吃。
- 非安全外环恰好一枚敌子：吃该子，送回其原始营地槽位并清空路线进度；行动席获得一次奖励，快速永久开全队门。
- 非安全外环恰好一枚同队：叠入，无吃子；已有≥2枚（同色或混色）：全部免吃，允许叠入，无开门/吃子奖励。
- 归家道只可能同席棋子，无敌子吃子；多子叠入不阻挡。叠子渲染缩小并轻微错位/数量标识，点击可明确选择具体合法棋子，不能靠绘制偏移改逻辑格。

本次动作结算优先级：精确归家标记→判胜→未胜时计算`extraTurn = dice===6 || captured || newlyFinished`→额外一次再掷或换席。6+吃子不奖励两次；归家+6也不奖励两次。经典第四枚归家/快速第一枚归家立刻胜利，禁止终局后额外骰子/AI回调继续走。

经典开局四子全营地，归家道开放，首席四子全部finished获胜。快速开局两子起点两子营地，先吃子开门后首枚finished获胜；一场可能较长且无保证步数，不用作弊点数强行缩短。重开不保留门/棋子/奖励；模式配置可保留，重新随机首席。

## 4. 状态机、AI、存档与生命周期

### 状态/输入

`loading → menu → setup → readyToRoll → rolling → choosing → moving → resolving → readyToRoll | celebrating → result`。设置/重开确认使用覆盖层暂停当前状态，后台暂停为生命周期标记而非伪造另一次掷骰。

|阶段|可接受输入|状态输出|
|---|---|---|
|loading|失败重试，不接受棋盘输入|核心图像解码完成才进菜单，缺素材明确错误|
|setup|切模式/席位/头像，开始|验证人数、至少一真人，创建新gameId|
|readyToRoll|当前真人骰子；AI延时调度|确定骰子、存档、进入rolling|
|rolling|只允许设置/重开入口|正常833ms后显示结果、产生合法动作|
|choosing|合法棋子点击|校验gameId/turnId/actionId，生成路线与结算计划|
|moving/resolving|棋盘/骰子锁定|按计划动画及一次性事务结算|
|celebrating|不可继续走子，可请求重开|庆祝完成显示result|
|result|同配置再来/回菜单|清理终局存档或保存明确result，不重复奖励|

AI只读取当前合法动作与已公开状态，不改骰子、不知道未来随机；轻量优先：精确归家→可吃子/快速开门→安全落点→推进→出营，评分平局在合法候选间随机。选择随机与骰子随机流分开，动画换帧不得消费规则随机流。默认思考约350～650ms，可暂停与取消；不承诺竞技强度。

### 事务与恢复

建议模块：`rules`纯逻辑（路线/合法动作/结算/不变量）、`random`、`ai`、`session`状态机、`storage`、`animation`、`renderer`、`input`、`assets/audio`。中文日志/注释，英文标识。

存档至少包含：schema/rulesVersion、gameId、turnId、actionId、模式、有效席/控制器/头像、棋子状态与绝对格、门权限、当前席、骰子结果、阶段、待选动作/已选子、冻结路线、动画段与elapsed、结算前快照/计划、是否已提交、奖励原因、赢家及随机流状态。读档验证格合法、席合法、finished数量、门/模式一致、事务ID与版本，损坏/旧版提示重新开始而非静默丢局。

- 摇骰开始先保存结果与随机状态；刷新rolling只能继续该结果，不重新取随机。
- 选子时保存不可变动作计划；动画基于结算前快照播放，终段完成后按actionId只提交一次结算与奖励，然后保存稳定状态。若崩溃，未提交则恢复该动画，已提交则不再次吃子或归家；状态变更与提交标志置于同一存档对象。
- 后台visibilitychange冻结单调动画时钟、AI计时与音效，保存elapsed；恢复前台继续剩余时长，不用后台墙钟一口气跳完。刷新允许从保存的动画段进度恢复，不能回到可掷骰状态造成重复。
- 所有异步带generation/gameId校验；重开/退出递增generation、清除timer/旧animation任务、取消旧AI、停止旧音效。动画/素材Promise迟到不修改新局。
- 设置面板暂停，关面板原阶段续播；声音关闭不改变规则和动画时钟。浏览器自动播放限制用首次真实操作解锁音频，失败不阻断玩法。
- 触摸与鼠标统一Pointer输入；坐标减canvas边界再逆缩放，使用同一命中表；防pointer/touch/click重复触发。

## 6. 五类动画标准

默认开启正常速度，所有棋盘动作期间输入锁定；设置/重开仍可操作并能取消旧局。降低动效设置不得把默认验收替成瞬移。renderer按animation pose绘制，不把规则最终位置提前当画面位置。

|类型|默认表现/时长|验收必须看到|
|---|---|---|
|摇骰|使用真实原版滚动帧，默认833ms，允许600～900ms；最后切真实结果面|多帧变化且顺序正确、中心不乱跳，结果与预存骰子一致，连点只生成一次掷骰|
|走子/出营|每个逻辑步一段弧线，默认110ms/格，允许90～130ms；升起/落地影子与轻微压缩，出营为单段营地→起点|经过全部path格，N步N次落地；不能直线飞最终格、跳格或出营多走6步|
|吃子回营|落点短强调约120ms，再沿受害者外环逆向路径回至其起点，最后一段回原营地槽；建议30ms/逆向格+180ms回营|被吃子持续可见的回程，不一帧消失/重现；只捕获一枚，开门和奖励只结算一次|
|归家|最后一步仍走90～130ms弧线；随后350～500ms缩放/光圈并进入本席停泊区|精确终点才触发，finished不能再选；停泊分槽不遮掩已归家数量，无额外逻辑步|
|胜利|默认1200～1800ms赢家光圈/彩屑/原版头像与庆祝，再出现结果按钮|先归家后庆祝、赢家正确、其他AI停止、结算和再来可真实点击|

动画时钟使用可暂停单调elapsed。每段保存起止逻辑格与持续时间，弧线例如线性位置加sin(πt)高度；不依赖帧率决定规则。叠子散开仅视觉，移动子置顶，终段重新排叠。

五类均需正常速度的连续截图或视频及时间记录：动画start/end、path与每格落地时点、帧序、actionId、visibility暂停段；截图至少覆盖起始/升起/落地/中间格/结束，摇骰多次换帧，长回营覆盖多个路径位置，庆祝含归家→庆祝→结算连续序列。单张截图或只打印日志不证明动画。对应重开、刷新、后台、慢素材加载的中间截断与恢复也保存证据；不借自动加速模式冒充默认。
