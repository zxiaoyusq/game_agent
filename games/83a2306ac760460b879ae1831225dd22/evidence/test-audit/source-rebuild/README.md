# LUDO · 原版美术复现

浏览器原生 Canvas 2D，经典 / 快速，2～4席真人与电脑同屏。经典四子精确归家获胜；快速两子预置，吃子永久开门，首子归家获胜；统一首名结束。骰子独立均匀，无连续六罚停或电脑点数操纵。

## 构建与运行
- Node.js 22或更新，`npm ci` 安装锁定的 Playwright 1.63.0。
- `npm run build` 生成 `dist/index.html`，通过任意静态HTTP服务器浏览该目录，支持独立子路径；无需远程资源。
- `npm test` 执行规则/存档/完整对局测试。
- `npm run check` 启动本地隔离静态服务器和真实 Chromium，验收最终dist，自动关闭服务，证据写 evidence/。浏览器需本机Chromium或Playwright浏览器，可通过 CHROMIUM_PATH 指定可执行文件。
- `npm run release` 在最终check后生成 releases/ 源码和试玩ZIP，不修改dist。源码ZIP内包括构建/验收脚本与锁文件，研究源码不打包。

## 操作
选择经典/快速与人数，逐席配置真人/电脑/空席（至少两席及一真人）。真人点击骰子或下方掷骰，点击高亮棋子或编号选择；叠子使用下方大按钮。电脑仅选合法动作。设置暂停；重开确认取消旧局；返回菜单仍可继续。存档包含摇骰结果及运动进度，后台冻结、刷新续播。损坏存档明确提示；写入失败持续提示。

## 素材与限制
真实棋盘、营地、棋子、骰帧、两张形象及音效来自用户提供的 Ludo Superstar 研究包，Just Ludo 仅规则补充。未生成AI整屏，不加载原包Cocos/广告SDK。引用来源见 workflow/art-manifest.json。**素材商业使用与再发布许可未核验，商用前需权利方核验。**
浏览器自动化是桌面Chromium及移动视口模拟，非真实手机/ADB验收。短横屏等比缩放，建议竖屏。默认正常速度动画；`?seed=数字`仅用于复现随机源，不改变规则或强制胜利。
