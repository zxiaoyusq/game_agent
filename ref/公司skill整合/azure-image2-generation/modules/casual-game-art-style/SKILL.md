# 休闲游戏美术指导

将**形式语言**与**本地化设计**分开。竞品只用于观察造型、线条/明暗/材质、UI组件结构和场景组织；不采用其配色规则、功能色分组、题材物件、角色或文化元素。

优先级：用户最新要求与玩法/资源契约 → 本项目简报与已选本地化方案 → 所选模板的形式特征 → 可选手段。模板是参考组合，不是强迫全屏变圆、变方、扭曲或斜切的规则。

## 项目简报与生成

按任务需要记录：玩法与素材契约、模板、允许迁移的形式特征、地区与方案、当地内容清单、UI家族、保持项与允许变化项。每轮替换被覆盖的选择，不累计历史指令；探索、整屏比较和精确素材生产使用不同约束强度。

实际提示词用抽取后的形式描述，不只写“像某游戏”；默认不把彩色竞品原图直接作为生图参考，防止其颜色和题材被一并继承。用户指定的本项目效果图不是竞品：生成时应实际输入对应效果图或完整局部，并依用户要求区分结构参考与外观参考。选型时可查看原始证据，但生成使用本项目的内容与配色参考。

## 必须守住的边界

- 玩法对象及身份缩略图的功能色独立优先；非玩法对象沿用本项目四级视觉职责与UI家族规则。竞品的配色和色彩层级不进入模板。
- 整屏保持协调的概括程度、绘制质量和空间逻辑；对象仍按功能与结构造型。棋子、UI、建筑、植物不必用同一种几何变形，不能只改前景而忽略场景，也不能为了统一而破坏棋盘、文字或点击区域。
- 图标低复杂度、高完成度；UI底板明确强于背景；背景有色有场景但低干扰。具体用色与强度只读取本地设计系统。
- 形式参考不授权改变玩法、代码、镜头、格位、视角或图集/alpha契约。参考截图不是像素锁，生产素材回到父技能对应管线。
- 用实际画面验收形式与本地化两个方面；不以提示词文字或文件数量证明画面通过。失败代表图先修，再展开已授权批量，不重复请求相同批准。
