# 九套七色地区方案

四级按最新视觉职责：商业化UI > 主玩法按钮/icon > UI底板 > 背景。七色是基调而非颜色上限，玩法对象独立功能色；没有商业化控件时不强制使用一级。共用规范见[设计系统](design-system.md)。
