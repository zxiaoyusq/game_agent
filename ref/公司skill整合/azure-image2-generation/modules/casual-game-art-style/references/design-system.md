# 休闲游戏设计系统

用于规划与验收，不整段注入生图提示词。先分对象，再选母版、地区方案和组件家族，最后调整视觉层级。

## 先分对象，再规划配色

|对象|判定与用色|
|---|---|
|玩法对象|棋盘棋子、收集物、直接参与规则的道具；功能色独立，允许丰富多彩，以玩法识别和状态区分为先|
|玩法身份缩略图|目标栏、任务栏中指代玩法对象的小图；延续对象身份与功能色，不套普通UI图标色|
|UI操作控件|返回、暂停、技能/工具按钮、付费或广告入口；按职责分级，再归入组件家族|
|UI底板|棋盘承托、目标/信息面板、工具条等容器；承托信息，与场景明确分离|
|背景|环境、场景道具与装饰；交代场所和地区氛围，视觉退后|

物件名称不决定类别：锤子参与棋盘规则时是玩法对象，锤子画在工具按钮里是UI操作图标。单素材只确认所属角色；多控件/多页面再盘点家族与状态，不强制所有小任务建立完整清单。

## 四级规范：只约束非玩法对象

|层级|对象|饱和度、对比度与完成度方向|
|---|---|---|
|一级|商业化UI：付费/看广告按钮及相关操作道具入口|最高强调；仅用于实际存在的商业化控件，不为展示层级新增入口|
|二级|主玩法操作按钮与UI操作icon|色彩鲜明、图形清楚、绘制完成度高，成为稳定交互焦点|
|三级|UI底板、棋盘承托面、信息面板、工具条容器|边界与内外色层明确，精修程度、对比度和色彩存在感高于背景|
|四级|背景场景与环境装饰|保留地区色彩、场景层次和可辨细节，以较低饱和度及局部明暗/边缘对比退后|

顺序为 **商业化UI > 主玩法操作按钮/icon > UI底板 > 背景**。玩法对象及目标身份缩略图不受四级用色约束，也不因商业化UI的存在失去玩法焦点。

这是相对视觉关系，不是要求逐像素数值排序。饱和度、局部对比与绘制完成度分别规划；不规定一级到四级面积逐级递增。精细度指轮廓、形体、边缘、色层、材质/绘制的完成度，不等于纹样或零件数量。

## 同组控件：统一家族，保留功能识别

同家族同变体共用底板、框架、图标主辅色、画法与状态逻辑；通过轮廓/语义/必要标签区分功能。比如同组工具按钮不能各自由配一套无关颜色。返回/暂停可取同一色板的子集；不同职责家族不强制长成同一按钮。

先给底板、边框、图标、文字和状态分配色彩角色，再绘制单个控件。主次CTA或危险状态需要区别时，定义统一变体；禁用是状态，不归为背景装饰。

按钮设计简约，但存在感不能弱。通过图标占比、负形、边界、物底分离与精确绘制增强交互；不退化为随手放上的通用小符号，也不靠增加花纹表现精致。

## 底板和背景分别处理

UI底板应有可辨轮廓、内外色层和稳定承托，不能与场景融成同一片浅色。用色、边缘和绘制完成度均应强于背景；厚度、倒角、投影是否出现由母版决定。

背景需要构图、场所感与文化内容。可以色彩丰富、可以有花纹和装饰，但在最终显示尺度下，其饱和度、局部明暗和边缘对比应明显弱于交互区，也弱于UI底板。通过相邻色值和宽尺度形体退后，保留颜色与可辨细节；不做空白底、灰白雾层或统一模糊。

|实际问题|只修相关变量|避免连带破坏|
|---|---|---|
|按钮弱、太随意|增强该家族的色彩、物底分离、轮廓和完成度|增加微装饰；只改一个按钮导致家族不统一|
|底板平弱、接近背景|恢复框架、内外色层和承托；立体处理服从母版|全屏提对比；给平面母版强加倒角和高光|
|背景抢眼|降低背景局部明暗、边缘反差和过高饱和度|连UI一起压弱；删除全部场景细节|
|背景失色、发灰|回补地区色相与适度饱和度，保留已成立的低对比|同时抬高阴影、亮部和纹样反差|
|图标繁复|保留大轮廓、宽色面和身份特征，删除缩小后成噪点的细节|把按钮缩小、压灰或画得粗糙|

## 地区配色与文化元素

每个目标国家/具体文化分支维护三套备选方案，每套七个基础色；允许近似色、自然明暗与必要中性色，七色不是颜色上限。七色按四级分配只是角色规划，当前示例为1/2/2/2，不是其他项目必须沿用的配额。

不同地区首先在大面积环境与UI体系的色相、冷暖和明暗基调上形成可辨差异，同时保留交互层级。当前[九套七色方案](regional-palettes.md)针对巴基斯坦、尼日利亚、菲律宾分支，是设计提案，不代表整个洲域或经调研证实的当地审美偏好。

文化身份优先由具体生活场所、物件轮廓和少量关键特征表达；不靠堆满纹样。配色与元素独立于画法：更换地区不应让七种母版都变成同一种渲染。

## 实际画面验收

先看最终显示尺寸/缩略图，再看高清局部：玩法身份与功能色 → 同组控件一致且醒目 → 底板明显强于场景 → 背景有色有场景且退后 → 图标低复杂度高完成度 → 母版差异与地区区分。

发现问题只返修对应对象与维度。提示词写了“简约”“分层”不算通过；文件数量和尺寸检查也不替代视觉检查。
