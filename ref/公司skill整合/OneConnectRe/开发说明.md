# One Connect 开发说明

项目保留 Construct 2 原版运行时，原始 ZIP、原始解包与 `baseline/` 保持只读。开发目录为 `game/`，本地 Git 记录每次迭代。当前进度和待确认事项见 `分析报告/One_Connect_DSH结果驱动开发计划.md`。

## 常用入口

- `启动开发预览.cmd`：启动本地预览和本地事件面板；事件记录不是平台上报或真实广告验收。
- `关卡编辑.html`：导入、编辑、检查和下载关卡配置。保存为 `config/levels.json` 后运行 `应用关卡配置.cmd`，重启预览。具体格式和尺寸限制见 `迭代接口文档/03_关卡配置与编辑.md`。
- `tools/build_game_package.py --output <新文件路径>`：刷新离线缓存清单、检查资源与原版连线/消除特效图集，并构建不覆盖已有文件的验证 ZIP。使用方法及回归说明见 `迭代接口文档/05_构建运行与回归.md`。
- `game/` 是开发版；`baseline/` 是原版对照；`config/levels.json` 是关卡源，`game/data.js` 和 `game/level-config.js` 由编译器生成，不应手工维护。

## 现状与边界

当前配置包含第 1–12 关，支持固定盘、受控可解随机盘、静态落位及已验证的向下/向右候选落位。未配置棋盘沿用原版生成与相应原版落位；未配置时间默认 300 秒。现有每套主题 20 个牌面，斋月备用牌尚未作为新增编号接入。竞品算法尚未完整解码，本项目生成器不是竞品原算法；第十关多方向落位和第十三关炸弹仍未还原。

首页从单个开始按钮进入已解锁关卡；最高进度、已完成的部分教学、锤子库存以及稳定的进行中棋盘分别保存。重新打开可恢复已验证关卡的牌位、时间、得分、提示和洗牌数量；教学中断会从该教学开头重新开始。切后台、失败和重开等已做部分 MuMu 回归，异常退出只能保证恢复最近一次稳定快照。

第 1、2、3、5、7、10 关有本项目引导；部分文案、手势和行为是基于已观察内容的实现，不能视为竞品细节全量还原。自动洗牌、锤子与引导的已验证范围见开发计划；实际玩法和回归结果优先于静态配置或截图。

广告事件、插屏策略和激励生命周期可本地模拟；真实 AHA SDK、正式奖励入口和持久经济链尚未接通。当前只规划 IAA，不开发竞品内购。接口说明见 `迭代接口文档/01_广告与宿主接口.md`、`06_CombiMons模板SDK接入.md`、`07_激励广告生命周期.md`。

浏览器与 MuMu 测试不等同真实 AHA 容器和真机验收。缓存更新可能导致首次启动仍使用旧版，下次加载才更新；未经同口径长期测试不能宣称整体性能优于原版。性能和包体数据见 `迭代接口文档/性能与Bug回归_20261030.md`。
