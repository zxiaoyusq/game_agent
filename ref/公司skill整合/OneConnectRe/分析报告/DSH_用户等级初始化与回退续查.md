# 用户等级初始化与高等级回退续查

请继续离线分析 `用户等级进度规则_续查.md` 中影响实际接入的未知项，不操作模拟器、不使用多模态、不修改 One Connect：

1. 追踪 `IUserLevel` 新存档的 level、score 初始值及初始化调用路径，说明默认 0 / 1 能否由反序列化或构造函数直接证实。
2. 精确读 `UpdateNextLevelInfo` 固定表和未命中分支，确定固定表 key、当前等级到目标配置行的映射，以及 `UserLevelId=-1` 行的选取、是否循环、随机种子与门槛。明确 `NeedScore=120` 到底作用于哪一级，纠正已有报告中与 `UserLevel+1` 查表可能不一致的结论。
3. 追踪 `UseRewardLayer.DoAnimation` 分子虚调用和持久化写入/重玩恢复，标注确证、推断和未知；输出函数边界、代码地址和可机读表。不得根据经验推测。
