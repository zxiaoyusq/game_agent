# 局内布局与四道具调整记录

## 依据与目标

- 用户提供同分辨率竞品截图：顶部状态区、中部棋盘、底部四个道具位、最下方 banner 区。保留本项目已确认的蓝色柔和立体美术，不直接复制竞品资源。
- 统一规划可用区域：棋盘和牌尺寸依据可用宽高等比例缩放，棋盘不得与状态栏、道具栏或实际广告区域重叠；有无 banner、竖屏比例变化和安全区均需考虑。广告未接入时不宣称已有真实 banner。
- 道具顺序参照截图：回转图标、锤子/魔法棒、洗牌、提示；四个控件的尺寸、底板、文字和点击区域使用一致视觉语言。
- 已有锤子为独立 HTML 按钮，提示和洗牌为 Construct 2 对象；涉及引导高亮、点击命中、暂停、库存及布局坐标的联动，不能仅修改视觉位置。
- 拆解资料只确认第一个位置的回转图标，具体功能未观察到。预留该位置，功能待证据，不以洗牌或其他效果冒充。锤子当前消除一对，与竞品魔法棒实际行为尚不能认定一致。
- 需要覆盖现有普通、异形、8×8、8×10、8×12 和原版回退棋盘，不改变配置、牌种、消除判定、存档指纹及原版连线/消除图集。

1. 定义画布与安全区坐标换算及统一布局参数，区分游戏绘制像素和页面 CSS 坐标。
2. 将顶部状态与原有提示/洗牌的绘制、触控和数量按新布局组织；同步引导高亮位置。
3. 新增同风格锤子控件并放入道具栏，保留其原行为；为未知回转道具预留清楚的未启用状态。
4. 按棋盘实际规格计算可用区域，确保重力、选中、连线、空格背景和恢复存档使用一致坐标。
5. 明确 banner 宿主占位与未接入时的布局，处理暂停、横竖屏切换、引导、失败/胜利界面。
6. 交付用户验收，针对反馈统一调整；真实广告 SDK 和回转道具行为另行接入。
