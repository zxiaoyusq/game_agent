# One Connect：界面、星星与动画迭代顺序

## 用户确认的方向

优先统一竖屏首页、局内、设置/暂停、胜利和失败界面；在此基础上加入星星相关局外系统与界面动画。参考 Tile Connect 的布局与交互，沿用本项目已经通过的深蓝色、柔和圆润立体美术。四个道具统一归组并给棋盘留出空间；纯 IAA，不做竞品内购、订阅及礼包。原版连线和消除图集保持。

## 现有证据与限制

- 首页参考：竞品 `screenshots/levels/00_first_launch_25s.png`，以及用户提供的单开始按钮、关卡进度截图；本项目已有可运行单入口首页。竞品头像、商店和付费活动不作为必需项。
- 局内参考：用户提供的同分辨率截图；上方时间/分数/关卡/暂停，中间棋盘，下方四道具及广告区域。本项目的 `analysis/ui_iteration_candidate_v2/game/` 是未验收的开发候选，具体功能和画幅均未 QA。
- 暂停参考：竞品 `screenshots/levels/63_paused.png`；资料记录继续、重玩、主页、主题和声音等。只在本项目已有对应功能或明确实现后提供入口，暂停不推进时间。
- DSH 后续核对：该截图存在，相关脚本记载以模拟点击进入暂停；图片本身不能证明游戏版本。`63_pause_t0.png` 与 `64_pause_t40.png` 字节相同，但尚未排除重复复制或采集链路复用，因此不能单独证明暂停期间计时被冻结。详见竞品拆解目录的 `07_程序与配置拆解/暂停截图来源核对与更正记录.md`；暂停界面层级及动作绑定仍待 DSH 继续提供代码证据。
- DSH 新交付 `07_程序与配置拆解/本地UI结构_层级与动画依赖.md` 与 `evidence/ui_hierarchy.csv`：暂停面板资源中包含继续、主页、重玩和主题节点，设置行嵌在同一面板；局内有计分、进度条和三颗星节点。以上是竞品本地资源结构证据，不能单凭对象名证明按钮绑定或运行时布局；具体监听、动画时长和缓动仍未确认。项目实现继续使用自身已确认的动作和音频接口，分别标注独立音乐、音效和振动尚无接入依据。
- 胜利参考：竞品 `screenshots/levels/19_after_L2_solve_b.png`，可观察三颗星及首页/下一关；首关直接进入第二关。排行榜真实性和星级规则尚不确定，不伪造在线排行。
- 失败参考：竞品 `screenshots/levels/28_after_shop_close.png` 与 `34_level5_state.png`；可参考状态结构，但不加入金币购买。激励复活须待真实广告 SDK 及回调契约确认后实现。
- 星星：现有资料提及局内得分星和星图、宝箱；是否为同一数据、计算阈值与累计规则未知。DSH 已接到补充任务，现阶段不将假设规则接入正式存档。
- 动画：当前只确认存在相关 DOTween/Spine 方法和素材，时长、缓动及触发未确认；新动效可先设计为项目自有候选，不宣称参数还原。外部素材接入按实际资源使用权与依赖确认。

## 分阶段实施

1. 首页：关卡进度、开始、设置入口与局外星星区域统一位置；尚无已确认功能的入口不伪装成可用。
2. 局内：状态栏、可容纳不同棋盘的中央区域、四道具栏及可选广告安全区同步布局；处理引导高亮、原生触控、暂停与屏幕尺寸。已有候选独立保存，用户负责 QA。
3. 设置/暂停：对照已存在动作及声音接口，整理开关和关闭路径，避免暂停期间计时或棋盘操作；不存在的设置不虚构。
4. 结算：分别处理首关直进、胜利、失败、重开、首页与下一关；星数显示在规则确认前作为不可误导的占位，不产生实际奖励数据。
5. 星星与局外系统：根据 DSH 确认证据设计本地持久状态、发放与幂等、版本升级、重玩、失败和退出恢复；无法证明的规则单独标记项目设计。
6. 动画：优先参数化实现面板进出、按钮反馈和星星变化；以 DSH 可证实数据标注来源，其他为自研。尊重减少动效、后台暂停和输入时序，不覆盖原连线与消除。

每项记录版本与改动，待用户实际验收；当前不运行模拟器和 QA。真实 AHA、广告 SDK、用户数据迁移及非目标分辨率均不能凭静态实现视作通过。

- 已在独立候选 v3 接入首页设置入口与统一声音开关，调用现有 GameSnacks 音频接口；尚未确认独立音乐/音效与跨会话保存，不声称设置页面和实际声音已通过验收。本次只构建，用户自行 QA。

- 候选 v4 为首页设置面板加入自研缩放进入、按压反馈和减少动态效果适配，并尝试阻止设置触控向底层游戏传播；竞品动画参数及交互效果均未验收。

- 当前事件表的 `Pause` 组在暂停时启用遮罩并设置 `pause=1`，创建原生暂停按钮；其中 `t22` 的帧 0 对应的动作会关闭遮罩、设置 `pause=0` 并销毁暂停控件。另有浏览器隐藏事件也会创建暂停控件。布局改造应保留这些动作及后台恢复路径，不能只用 DOM 遮盖或直接修改暂停变量替代。以上为静态代码定位，完整触控、时序和多画幅仍待用户验收。

- 新增 tools/result_panel_candidate.js 展示组件草案：胜利/失败、关卡、分数和首页/下一关/重试按钮仅显示调用方提供的真实状态；星数不传则不显示。组件未接入游戏、不修改存档或发奖，事件与按钮 owner 尚待对接，未 QA。

- 结算展示组件提供独立 HTML 设计预览；预览中的关卡与分数为示例，按钮只关闭预览，不触发游戏行为。原奖励弹窗、首关直进、胜负事件和进度更新的最终对接仍待完整实现，未进行 QA。

- 独立预览启动脚本支持选择候选目录与端口。v6 使用单独端口 18762，不修改之前的 18761 预览；各端口既有本地存档保留，不操作 MuMu。服务启动不等于 QA 通过。
