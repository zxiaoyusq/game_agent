# DSH 精简交接约定

- 逆向和美术成果继续保存在各自既有工作目录，不移动历史文件。每个任务单独写交接摘要到 `analysis/dsh_handoff/`，文件名用稳定英文任务名，不新建 HTML。
- 摘要优先简短：任务名、状态（进行中/完成/受阻）、当前基线或分支、结论及证据路径、未知或风险、验证范围、下一步。只列相对项目根目录的产物路径；项目外证据用绝对路径。以信息完整为准，不机械压缩。
- 固定操作入口为 `tools/dsh_handoff.md`；审核游标只在主代理核查消息和证据后显式更新，不因重复查看自动确认。报告仍以原始证据为准。
- 默认先读紧凑状态；发现未审核消息后按需用 `--session reverse --unread` 或 `--session art --unread` 查看增量，再按标记查完整记录和相关证据。单任务摘要放 `analysis/dsh_handoff/<任务名>.md`，原始产物无需复制或搬迁。
- 内容有实质变化时更新对应摘要，不复制完整报告或终端日志。报告和原始证据保持独立，主代理仅在判断、实现或核验需要时读取。
- 主代理先看会话状态、摘要及 Git 差异；完成后按既定版本检查点核对证据和整合。界面由主代理对照已批准效果图亲自复核和修正。
- 会话仍在执行时不重复派发、不抢工作区；仅删除自己确认废弃且可重建的临时文件，保留交付、验收与回滚证据。
