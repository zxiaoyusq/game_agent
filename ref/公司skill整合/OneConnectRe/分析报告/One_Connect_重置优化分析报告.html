API 契约

API调用时机回调注意
h5sdk.gameLoadingCompleted()资源全部加载完无必须调，否则平台判超时
h5sdk.adBreak({type:"preroll"})游戏启动（外层自动）adBreakDone外层已配，无需游戏内触发
postMessage("next") + MIAD_NEXT关卡间插屏_callback=完整观看
_failback=失败/跳过		45秒频控；失败也必须继续游戏
postMessage("reward") + MIAD激励视频（复活/道具）_callback=发奖励
_failback=不发奖励		failback 不得卡住流程

改造代码示例

// 替换 host-adapter.js 中 showAd 的实现

// 1. 插屏（关卡间，不阻塞）
function showInterstitial(onDone) {
  window.parent.MIAD_NEXT = {};
  window.parent.MIAD_NEXT._callback  = onDone;  // 看完
  window.parent.MIAD_NEXT._failback  = onDone;  // 失败/跳过也继续
  window.parent.postMessage("next", "*");
}

// 2. 激励视频（复活/加时/道具，阻塞等回调）
function showRewardedAd(onReward, onFail) {
  window.parent.MIAD = {};
  window.parent.MIAD._callback = onReward;  // 看完 → 发奖励
  window.parent.MIAD._failback = onFail;    // 跳过 → 不发奖励
  window.parent.postMessage("reward", "*");
}

// 3. 加载完成通知
function notifyLoaded() {
  window.parent.postMessage("gameLoadingCompleted", "*");
}

5.6 伪排行榜

完全离线，无需账号。本地存储玩家昵称（首次进入自动生成本地名字如 "Ahmed_PK_7823"）。榜单 Top 10 中 8 个预制玩家，分数每天按玩家当天最高分 ±15% 随机刷新。玩家自己永远排第 3–5 位（营造"差一点就超越"的竞争感）。名字库按国家分布生成：巴基斯坦/印度/尼日利亚/菲律宾各占比匹配 DAU。

6 版权风险

⚠️

Famobi 原版仍活跃（2026.6 更新），代码中有 Famobi 标识

项目代码中含 window.famobi_gameID = "onet-connect-classic"、Famobi analytics 全套、以及 Famobi 图集。 com.famobi.onetconnectclassic 在 Google Play 仍在更新。

建议处理方式：
1. 先确认是否持有 Famobi 授权（重新分发许可）
2. 无授权 → 游戏规则本身不受版权保护，但代码逻辑需重写、图集/音频必须全原创
3. 游戏名称更换为非 "ONET/Onet Connect" 开头的名称
4. 移除所有 famobi_gameID、famobi_analytics、html5games/ 引用
