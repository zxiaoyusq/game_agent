# Tile Connect 关卡拆解：One Connect 开发参考

记录时间：2026-10-30。参考 DSH 会话 `session-f2e79f49-7150-4f0c-88ae-8d7f9a34b729`，以原始取证和配置为准。竞品为 Higgs Studio 的 Tile Connect — Matching Games 1.19.9；与当前 Construct 2 One Connect 是不同游戏，配置不能直接导入。

## 可参考的设计

1. **首关教学**：竞品第 1 关使用固定小棋盘、手指和目标高亮，引导玩家逐对消除，再示范绕行；后续开发可先设计适合 One Connect 的固定教学棋盘和操作步骤。具体文案与美术需另行设计。
2. **逐步介绍计时和道具**：竞品第 3 关的计时教学有截图与静态配置；第 5、7、10 关教学脚本存在，但触发过程仍待自然验证。可以借鉴分阶段引导思路，不把后续关数视作已验证体验。
3. **棋盘与难度配置分层**：可参考按关卡分离时间、棋盘形状、牌型和教学步骤。One Connect 当前可编辑每关时间与固定 6×12 棋盘；空洞、尺寸变化、牌型分布和机关尚未支持，必须先核实原运行逻辑并逐项实现。
4. **连线规则**：竞品的最多两次转弯及棋盘外围绕行有实测记录；One Connect 的连接规则需要用原版局面逐项对照验证后再作为设计约束。不要把竞品规则直接当成原版事实。
5. **随机棋盘与可解性**：竞品早期关卡重复进入时牌面有变化，可参考固定形状搭配可变化牌面。每种牌数量为偶数仅是必要条件，不能保证存在完整消除路径；应分别验证初始可连、生成后的完整解路径、无解时洗牌及洗牌后可继续。不要把竞品报告中“偶数保证可解”的表述当成已证结论。
6. **后续扩展**：斋月主题牌面保留为未来资源；新增牌型前要确认运行时帧编号、资源映射、编辑器和配对规则，不将备用图直接视为已支持的新牌型。

## 证据边界

- 会话仍运行，未完成第 1–10 关及 15/20/30 关的自然取证。报告与会话对第 3 关通关情况存在冲突；不将其作为已完成的稳定结论。
- 第 2 关有自动操作清盘及结算截图；第 3、4 关计时分别有 163、243 秒观测与静态配置对照。自动全对扫描属于自动操作实测，应与人工自然游玩区分。
- 第 4 关曾两次误判通关并被撤回；更后关卡字段主要来自静态表，实际机关、引导和重玩表现仍待验证。
- 配置中的 `repeat`、方向开关等字段含义仍需进一步验证；不以字段名或相关性直接断定运行算法及难度效果。
- 竞品数据适合参考机制与节奏，不证明 One Connect 的原版行为、真实广告接入或玩家留存效果。

## 后续开发顺序

先补充 One Connect 原版规则及棋盘生成/洗牌的对照测试；然后设计可解性校验与测试案例；再扩展关卡配置和编辑器；最后以可关闭、可复用的步骤式引导逐步接入。每一步保留原版基线、独立验证，并注明是否为新增设计。
