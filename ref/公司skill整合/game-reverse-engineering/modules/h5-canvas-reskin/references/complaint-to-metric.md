# 主观抱怨 → 可测指标

> 范围：`GENERALIZED_PATTERN`。**本文件是全模块最该被复用的一份。**
> 用户不会说指标，只会说感觉；每次都要先把一句模糊的话翻译成可测的量，
> 否则**既无法迭代，也无法验收**。

## 使用方式（四步）

1. 收到一句主观反馈，**先在这张表里找它对应哪一行**
2. 表里没有 → **先把这句话翻译成一个可测的量**，再做任何修改行动
3. 量成品时**必须同时量原版** —— 判据几乎永远是「**与原版的相对关系**」，不是绝对值
4. 修完**用同一个量复测**，并把数字写进报告 —— 这是"改好了"的唯一证据

## 映射表

| 用户原话 | 容易先怀疑的 | **实际可测的东西** | 来源案例结论 |
|---|---|---|---|
| 背景太花 | 饱和度 | **边缘密度（梯度均值）÷ 原版** | 3.25× → 定位到具体是哪张背景 |
| 立体感 / 对比度不够 | 明暗跨度 | 明暗跨度 + 高光占比 + 对比 | 必须与"别花哨"反向搭配，三个维度分别调 |
| 特效用看不清 | 特效资源被改坏 | **特效所画承托面的亮度差** | 特效是原版没动；承托面暗了 75 |
| 和原版的 **alpha 范围**不一致 | alpha | **可见区亮度分位点** | **根本不是 alpha，是亮度差 40~50** |
| 卡死 / 无法拖动 | 游戏进程死了 | **`canMakeMove()` 的每一个条件项** | 游戏活着，是输入被锁存标志关了 |
| 图标没文化符号 | 画得不像 | **提示词里有没有「形状名词」** | 只写材质 → 模型保持原轮廓 |
| 某资源"看起来没被使用" | 名字对不上 | **代码键 vs 包内文件**两清单对账 | 键名 ≠ 文件名 |
| 缺元素 / 语义丢了 | 模型没画好 | **原图 alpha 连通域个数** | ≥2 = 复合图标，需点名保留 |
| 拼接没拼上 | 切图坏了 | **真实相接配对**的接缝差值 | 条带顺序反了，且自检也量错了配对 |
| 包体暴涨 | 生图太大 | **真实容器格式** | WebP 伪装成 .png，回写换了容器 |
| 换色后"变脏了"/"发黑" | 提示词不好 | **可见区纯黑像素占比** | 亮度拉伸叠加更深暗侧 → 纯黑 2.1%→30.8% |
| 六种棋子分不清 | 形状不像 | **最小主体色相间距** | 19.7° → 5.7°（重画挪了色相） |
| 底板"比原版弱 / 融进背景" | 对比不够 | **底板 vs 背景的强度差**（饱和度/局部对比/边缘） | 三级必须明显强于四级 |
| 更新了但"看起来没变" | 真的没更新 | **对照页的生成时间戳 + 两侧来源路径** | 页面没写时间戳，无法判断新旧 |
| 界面文字/标签错了 | 字体问题 | 文档/页面里的**文案字面值** | 案例里写着"东南亚"实为"南亚" |

## 这些量怎么取（通用做法）

| 指标 | 定义 |
|---|---|
| 边缘密度 | 亮度图的梯度幅值均值（`sqrt(gx²+gy²)`），只在可见区统计 |
| 局部对比 | 可见区亮度标准差 |
| 明暗跨度 | P95 − P5（或 P99 − P1） |
| 高光占比 | 亮度高于某高分位的像素比例 |
| 饱和度 | 可见区 `(max−min)/max` 的均值 |
| 主体色相 | **高饱和像素**（如饱和度 ≥ 自身 P60）的中位色 → HSV 的 H |
| 覆盖率 | 可见像素数 ÷ 原版可见像素数 |
| 纯黑占比 | 可见区内亮度低于某下限的像素比例 |
| 接缝差值 | 相邻两段**真实相接**的首/末行 RGB 均差 |
| 强度层级 | 背景 vs 交互区，三项各自比较 |

**统计口径必须写清**（是否排 alpha、阈值多少、用均值还是中位）——
否则"同一个指标"在不同脚本里会给出不同结论。

## 两条最贵的经验

**① 方向可能完全反了。** 表中「和原版 alpha 不一致」与「卡死」两行，
我最初怀疑的方向（alpha / 游戏死了）与真实方向（亮度 / 输入被锁存标志关了）**完全不同**。
**先量，再动手。**

**② 阈值型判据会漏。** 底板那种「大面积亮胶囊 + 一块暗图标」的分布，
中位数可能已接近原版、均值却差 40~50 —— **用中位/跨度判"要不要修"会误判"不用修"**。
对这类分布要改用**无条件分位点重映射**。

## 反向坑：别把指标调过头

| 指标 | 调过头的后果 |
|---|---|
| 背景边缘密度 | 降到远低于原版 → **退化成空白纯色底**，同样不合格 |
| 亮度 | 无下限地拉伸 → 暗侧塌成纯黑（来源案例纯黑占比 2.1%→30.8%） |
| 饱和度 | 一律降饱和 → 变成灰雾，不是"低调" |
| 色相回锁 | 连同形状一起改 → 把新画法压平 |

**每一项都要有上下限，且下限同样要验收。**
