怎么使用

一次只看一关，图片、配文和出处放在同一屏。

  1. 在左边选择关卡，中间看原图，右边修改配文和出处。
  2. 确认图片与文字一致后，把审核状态改成“图片与配文匹配”或“修改后已确认”。
  3. 随时点“保存草稿”。这一步只保存你的工作进度，不会改游戏工程。
  4. 全部核对后点“预览并写入”。先看新旧差异，再确认写入工程。

以后新增关卡时，编辑器会自动读取新关卡。缺配文或出处的关卡会显示“待补全”。正式写入前会自动备份原文件。
