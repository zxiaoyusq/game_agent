# SDK 替换链路义务清单模板（Obligation Ledger）

> **何时读我**：SDK 替换任务开工要先钉 A/B/C 档位，或交付前要逐条确认「这件事到底算不算做完」。
> **读完能做到**：按档位裁剪出本项目的义务清单，逐条回填唯一 owner、验证方式、证据类型与证据路径，并分清已闭合、未闭合和已豁免。
> **范围**：`GENERAL_DEFAULT`

范围：`GENERAL_DEFAULT`。本模板定义 SDK 替换链路「什么算真正完成」，按 A/B/C 档位实例化，交付前逐条关闭。

原则出处：`modules/sdk-replacement/SKILL.md` 证据等级表与三档结局定义。核心纪律：静态字符串消失、logcat 干净都不能单独证明断网完成。

## 关闭规则

一条义务同时满足四件事才算**已闭合**：

1. **唯一 owner**：负责证明该项的脚本、命令或责任人已写明。
2. **规定证据类型**：取得的证据与档位要求一致。档位判定类义务必须真机网络证据，模拟器只做阶段回归。
3. **验证器通过**：verify 门禁、抓包分类或验收报告产生可复核输出。
4. **证据落盘**：证据路径写入本清单与交付报告。

缺任何一件即为**未闭合**。档位降级（如 C 档不做）不是未闭合，是**已豁免**：需用户确认档位变更并写进验收契约。

## 使用方法

1. 任务开始时先钉死 A/B/C 档位，再复制本模板删除不适用档位的义务行。
2. 验证方式写不出来的义务，先登记未知清单（根 `references/unknowns-ledger-template.md`）。
3. 每完成一项立即回填证据路径与状态。
4. 交付时本清单随报告交付，未闭合项逐条列出。

## 常见错误关闭（不得作为关闭依据）

- 「静态扫描不到原厂类」≠ O-K5：字符串消失不说明连接消失，反之字符串残留也不说明连接还在。
- 「logcat 无原厂关键字」≠ O-K5：网络层结论只认 DNS/TLS/Host 三层抓包。
- 「模拟器全绿」≠ O-K8：模拟器只做阶段回归，最终结论必须在真实联网手机上获得。
- 「目录大小一致」≠ O-K4：Seed 完整性只认文件存在性 + 哈希 + manifest 自洽。

## 与未知清单的关系

域族归属拿不准、隐藏入口未定位、平台后台无法确认等事实缺口，同步登记根 `references/unknowns-ledger-template.md`，两清单编号互相引用。交付结论必须同时给出：已闭合义务的覆盖范围、未闭合义务清单、未知清单。
