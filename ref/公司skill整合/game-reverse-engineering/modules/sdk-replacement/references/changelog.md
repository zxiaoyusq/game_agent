# sdk-replacement 版本记录

> **何时读我**：想确认本模块某个能力是哪一版加进来的，或手头流程到底对应哪个版本。
> **读完能做到**：按版本号查到每轮新增的能力与门禁出处，判断当前做法是否已过期。
> **范围**：`GENERAL_DEFAULT`

- **1.2.0 (2026-10-12)**：新增未接广告反馈专项；将文案/结构/触发证据分开，覆盖同步返回身份预登记、attempt 与 claim 双重幂等、失败终态、加载与播放计时、provider 回调顺序、弹窗暂停归属及真实业务回调 QA。明确 inert success 不能应用于广告奖励/支付。

- **1.1.1 (2026-09-13)**：补充 consent 跨进程持久化、adapter 初始化前恢复及 QA 隔离存储要求。
- **1.1.0 (2026-09-13)**：新增 Godot 重构时的 vendor-neutral 插件模式、同意/服务双门禁、广告 policy、稳定 AB 边界、奖励 proof 幂等账本、事件契约与导出资源门禁。
- **1.0.0 (2026-09-04)**：新建模块。整合 V35 原厂隔离+真机验收、SeedCopier 离线内置、远程 Bundle 证据链与缺失脚本重建为通用八阶段一条龙；全部脚本参数化，案例数值只作示例。
