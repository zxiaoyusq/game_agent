# 美术换皮链路义务清单模板（Obligation Ledger）

> **何时读我**：哥哥要判定一次换皮任务"到底算不算完成"，或交付前被问"你凭什么说这个做完了、证据在哪"时。
> **读完能做到**：在任务开始时实例化这份义务清单，用"唯一 owner + 规定证据类型 + 验证器通过 + 证据落盘"四条闭合规则逐条判定 O-S1~O-S10，识别"文件已复制""Alpha 一致""首页正常""生成图好看"这四类伪关闭依据，交付时给出已闭合范围、未闭合清单与未知清单。
> **范围**：`GENERAL_DEFAULT`

范围：`GENERAL_DEFAULT`。本模板定义换皮链路「什么算真正完成」，任务开始时实例化，交付前逐条关闭。

原则出处：`modules/skinning-pipeline/SKILL.md` 交付门禁。核心纪律：复制动作、Alpha 一致、静态截图都不能单独证明换皮完成。

## 关闭规则

一条义务同时满足四件事才算**已闭合**：

1. **唯一 owner**：负责证明该项的脚本、命令或责任人已写明。
2. **规定证据类型**：取得的证据与本行声明的类型一致。声明「真实播放」的不能用 atlas 展开图替代。
3. **验证器通过**：skinpipe 门禁或对照检查产生可复核输出（manifest、diff、verify 报告）。
4. **证据落盘**：证据路径写入本清单与交付报告。

缺任何一件即为**未闭合**。状态允许**已豁免**：豁免需用户明确同意并写明理由，降级省略的资产不许静默消失。

## 使用方法

1. 任务开始时复制本模板，按当前项目资产清单增删义务行。
2. 验证方式写不出来的义务，先登记未知清单（根 `references/unknowns-ledger-template.md`）。
3. 每完成一项立即回填证据路径与状态。
4. 交付时本清单随报告交付，未闭合项逐条列出。

## 常见错误关闭（不得作为关闭依据）

- 「文件已复制」≠ O-S5：复制动作不说明元数据守恒，也不说明引用方更新。
- 「Alpha 一致」≠ 语义正确：Alpha 相等只证明几何通道，不证明轮廓语义与附件职责。
- 「首页正常」≠ O-S8：静态首页通过不代表章节、排行、每日、结算功能仍在。
- 「生成图好看」≠ O-S1：未做运行资源链映射就批量生图，画得再好也可能贴错职责位。

## 与未知清单的关系

映射不到位、运行时引用无法确认等事实缺口，同步登记根 `references/unknowns-ledger-template.md`，两清单编号互相引用。交付结论必须同时给出：已闭合义务的覆盖范围、未闭合义务清单、未知清单。
