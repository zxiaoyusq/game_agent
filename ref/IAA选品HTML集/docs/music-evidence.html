1. 证据口径

所有排名直接来自公开 HTML 的 window.__APP_DATA__.layout.data.apps，不是列表序号：

  • U = usageRank，Similarweb 的当前安装量与过去 28 天活跃用户混合使用排名，不是 DAU，不是具体活跃人数。

4. 四条细分机会与取舍

下述 IAA 位置是产品设计推断，不是已实测竞品广告位；所有六个 GP 参考均明确 Contains ads 与 In-app purchases，属于混合变现先例，不能称纯 IAA。

优先级 / 细分主证据与机会动作门槛声音、弱网、低端机IAA 自然位短局复玩风险
P1A：短段钢琴块 / 点按连击Piano Beat + Magic Tiles 3；7国重复出现，Piano Beat 肯 Games S16。先验证宽容判定、低密度短乐段，而非直接复制高速谱面入门规则简单，但多轨识别、左右手协调、连续点击、加速和漏键惩罚使上限高；不应泛称低操作2D可控，但卡顿和输入延迟直接影响公平；本地预置少量曲段、可选缓存、离线可重玩。静音可按视觉操作，但音乐反馈与满足感会下降失败后可选复活；曲段结算奖励加倍；明确自愿解锁曲段/外观。开曲与演奏中不插广告短段可降低重开成本；过短而每局强制广告会令广告时长超过游玩。重复前奏、失败首段循环、以复活填容错都伤留存
P1B：单指节奏跳球 / 路线追踪Tiles Hop 埃 S4/U3、南非 S9/U5、印 S7/U7；比只做琴键更宽玩法。可用可视路线、宽平台、缓节奏差异化手指数少，不代表负荷低：持续横向追踪、落点预判、平台间距和突然变向构成门槛；需避免窄跳台与早期高速声音增强沉浸，视觉落点可保留部分静音可玩性。低特效简背景、稳定帧时比炫光优先；基础曲段离线，音乐包预缓存掉落后一次自愿续跑；结算；球皮肤与主题试用。不可在连续跳跃中切断声音曲段可复玩，但坠落几秒即广告、拖动灵敏度不稳定、从头重复长曲会强挫败；需复活频控与短段检查点
P2A：节奏射击 / 按住拖动瞄准Beat Fire 巴 S10、孟 S7；同时有 Rhythm Fire 与 Rhythm Shooter 榜单信号，南亚值得独立创意测试真实动作是 hold & drag 瞄准，不是单次点击。追踪下落目标、节拍与屏幕遮挡叠加，中等或更高反应压力枪声和节拍是差异点，静音价值损失较大；闪光/粒子控制，避免枪声延迟。单人预置曲段可离线，广告收益仍需联网失败续局、武器皮肤试用、结算翻倍；不在连射中强插单一节拍易疲劳，过强音效/失败即重播影响耐受；区域榜信号较集中，不应直接七国同配置铺开
P2B：配色音乐跑道 / 滚球收集Dancing Road 的“节奏+颜色识别”是扩玩法参照；但本次七国数组未见，不当当前头部证明滑动方向+颜色选择双任务；变色节点、拥挤色球提高认知与反应门槛；需形状冗余避免单靠颜色视觉跑道使静音仍可能可玩，但届时更接近跑酷而非纯音游；简化材质和远景，稳定帧时；离线基础路线撞错色后的自愿续跑；终点奖励；外观解锁失败多来自看不清或镜头遮挡会显得不公平；颜色换皮内容深度有限，不能只靠新歌解决跑道单调

国家测试重点（假设，不是市场收益排序）

  • 印度 / 埃及 / 南非：能同时观察 S、U，适合验证“下载吸引力与重复使用”差异；埃及 Magic Tiles 3 S1/U1、Piano Beat S2/U2、Tiles Hop S4/U3，为点按与跳球双线提供直接信号。
  • 肯尼亚 / 尼日利亚：优先把 Piano Beat 式短段点按列首轮；肯 Games S16 是跨分类证据。U缺失，必须依赖自己的留存/会话数据，而非假设活跃高。
  • 巴基斯坦 / 孟加拉国：点按仍为主线，音乐射击为创意对照。Piano Music Heart Games S24/S13 是跨分类支持；非“用户只接受超低操作”。
  • 网络和低端设备是需测的产品条件，不把七国所有用户概括为同质低端机。离线可玩能降低中断风险，但离线期间无法等同获得 IAA 收益；不能用离线标签推导广告填充或 eCPM。

5. 与箭头 / 消除的差异

  • 箭头（以空间方向/顺序解谜为例）：可停下来想，静音基本不损失核心体验；音游是持续实时反馈。箭头更适合不确定打断场景，音游以节奏快感、技巧成长与曲段收藏形成不同复玩动机。
  • 消除：主要是盘面规划、目标和连锁反馈，可容纳较长关卡内节奏起伏；音游依赖时间轴连续性，不能借用“任何时刻都能插广告”的思路。
  • 音游的广告自然位是失败/曲段结算/自愿内容或外观奖励；箭头可用提示、撤回，消除可用步数、道具。不能把失败强迫复活当作音游自然高变现的保证。
  • 音游比箭头/消除多了音频与触控时延、曲段内容、帧时一致性的工程成本，但2D点按和简化跳球不是天然重度产品。应把 P1A/P1B 与箭头/消除并行做小规模验证，而非因这些成本直接降为不做。
  • 首轮看首段完成率、连续失败后的退出、短段复玩、D1/D7与会话、低端设备帧时和时延、静音占比、联网覆盖、广告展示/留存损失；排名只能指导选品，不能代替这些指标。
