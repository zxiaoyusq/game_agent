# IAA选品汇总：范围、依据与下一步

## 我们这轮要解决什么

这次IAA选品，我希望从非洲、南亚用户的实际娱乐需求出发，先把范围打开，再根据数据和体验逐步收敛。我们要找的是有大众用户基础、规则容易理解、操作负担可控、能够反复玩的产品，而不是必须长得像消除游戏。

Bubble Shooter、俄罗斯方块以及直接重复的填格消行方向，我们已经验证过，本轮不再重复立项。音游先不考虑版权因素；但仍然需要评估音画同步、谱面制作和内容更新能力。

## 当前共识：14组机会池，先比较8条主线

优先横向比较：**轻音游、单人纸牌、地区牌棋、贪吃蛇／吞噬、轻跑酷、轻驾驶、轻体育、视觉解谜。**

另外保留点击街机、同机小游戏、涂色／拼图、轻服务经营、宠物养成／解压等机会。进入候选池不等于立即开发；暂时缺少数据，也不直接等于没有机会。

|用户需求|我们要重点研究的方向|要验证的问题|
|---|---|---|
|低文字、即时反馈、重复练习|轻音游、贪吃蛇、跑酷、轻街机|规则简单是否真的等于操作容易；新手能否获得正反馈|
|熟悉规则、长期娱乐习惯|单人接龙、当地牌类、Ludo、Domino、Carrom|当地熟悉者占比、规则版本、对手AI和完整牌局体验|
|现实题材和可理解目标|轻足球、板球、台球、轻驾驶|能否把玩法做轻，而不是完整复制重型竞品|
|不依赖反应速度、逐步完成|视觉解谜、涂色、拼图|内容供给、可解性、完成感和广告打断|
|简单动作带长期成长|轻经营、宠物互动|成长循环是否成立；美术、年龄定位和运营成本|

## 如何阅读这套新增数据

我们补充参考产品的Google Play公开下载档位、评分、评价量、更新时间和商店链接，让讨论不只停留在品类名称。

但必须分清：
- **全球累计下载档位不是当前装机量。** “100M+”只能说明达到公开累计下载量级，不能说目前有一亿用户，也不能当作某个国家的下载量或DAU。
- **商店评分不是无条件可比较的全球统一分数。** 这轮尽量使用统一语言和地区视图，保留来源、采集时间、评分／评价量的原始标签。不同终端和时间仍可能不同。
- **S是商店排名，U是使用排名。** U综合安装和近28天活跃因素，不是DAU人数。总榜、分类榜分别比较。
- **外部行业数据只提供背景。** 地域、统计期、平台和指标定义必须一起看，不能用全球增长或行业收入直接预测我们的IAA收益。
- **缺失保留为缺失。** 不用零或推算数字填满表格；未进入公开样本，也不等于没有市场。

## 现阶段的数据支持什么

跑酷、贪吃蛇、轻驾驶、轻音游、轻体育等方向已经找到目标国家的游戏总榜产品信号；单人接龙在多国纸牌分类榜有表现；地区牌类需要结合熟悉人群和当地规则理解。

这些证据足以支持扩大候选范围，但还不足以证明某款新产品一定有高DAU或能实现IAA盈利。我们暂时没有取得Apollo的实际DAU数据，也没有竞品广告收入占比、同国CPI和留存数据，不应给出伪精确的收益排名。

## 后续怎么筛选

1. **先看市场。** 每条主线尽量比较不同开发商的代表产品，补目标国家28／90天趋势和公司渠道数据。
2. **再看用户。** 区分完全新手和玩法熟悉者，观察理解规则、第一次成功、主动再玩和完整对局。
3. **验证广告。** 音游不能中途断曲，纸牌不能每一步插屏，对战不能看广告改牌；IAA需要在不破坏核心体验的前提下成立。
4. **最后比较交付成本。** AI、物理、内容、网络和低端机适配是实际约束，但不应在市场研究前把整个品类排除。
5. **从3—4个不同用户动机的验证候选中，决定开发1—2款。** 不预设最后一定在两个相近的解谜产品中选择。

## 交互报告怎么用

- 在“产品库”按玩法、国家和证据范围筛选，点击产品查看指标定义与来源。
- 勾选最多4款产品对比；用“候选”按钮保留讨论名单，并填写本地备注。
- 在“国家榜单”分别查看总榜和分类榜，不把它们混成一个名次。
- 在“行业背景”查看报告日期、统计期、地域、原文摘录与限制。
- 在“文档集”阅读全部历史材料。第一轮报告是阶段性子集，最新宽口径候选池才代表当前范围；原文保留是为了追溯，不代表旧优先级仍是最终结论。
- 筛选结果、候选名单和数据均可导出。候选和备注只保存在当前浏览器，不会上传或自动同步到飞书。

**整体原则：从用户画像出发宽选，用目标国数据、真实体验和商业化验证逐层收敛。**
