IAA选品交互HTML报告集

打开方式：
1. 推荐先解压整个文件夹，再用Chrome或Edge双击index.html。无需服务器或安装依赖。
2. index.html是自包含总入口，产品、榜单、行业资料和所有文档已内嵌；单独分享该文件仍可使用主要交互。
3. docs/下每份原文也有独立HTML，可搜索、打印；sources/保留Markdown。
4. data/含补充后的70款商店数据、32款核心目录、1404条榜单和行业证据。evidence/store/为可读采集摘录。

功能：搜索、玩法/国家/证据筛选、排序、最多4款对比、候选收藏和备注、CSV/JSON导出、文档全文检索、打印。
本地候选与备注不上传；浏览器存储限制时会提示，请导出CSV备份。外部商店和来源需要联网。

口径：下载档位是全球累计下载量级，不是当前装机量或DAU。评分为hl=en&gl=IN视图，ratings count不等于文字评论数。S/U分开，0缺失。行业历史基线/预测有独立时期和地域说明。
榜单快照：2026-09-18。商店采集：2026-09-21T13:02:19.616Z。资料生成：2026-09-21。不是实时服务。

完整性：12份文档；32核心+38补充参考；4条行业指标。旧阶段文档保留并标记，不应当作最终结论。
