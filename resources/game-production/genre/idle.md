# 放置与增量经营

状态：初始知识指南；本项目尚无该品类完整成品验证。

## 核心状态与循环

状态包含货币、生产设施、升级、收益倍率、解锁、最近结算时间和已领取事件。循环为积累产出 → 选择投资 → 提升效率或解锁 → 达成阶段目标；是否有重置成长由产品决定。

必须决策：在线产出粒度、离线收益上限与领取方式、是否暂停、成本增长、倍率叠加顺序、大数表示、时间来源，以及浏览器本地存档还是可信服务端结算。

## 规则不变量与数值

- 购买按当前价格一次性检查余额、扣费和升级；重复点击不能超买、负余额或重复获得奖励。
- 收益结算只消费一次时间区间，前后台切换、刷新和重载不重复发放。活动会话计算与持久时间戳要明确配合方式，不能简单依赖画面每帧加钱。
- 时间倒退、异常跳跃和超长离线按明确策略处理。纯本地时钟只能做边界保护，不能宣称具备可信防作弊能力。
- 货币始终为有效非负值，检查溢出、精度及界面格式；长时模拟和快速购买不得产生 NaN 或无穷值。
- 用同一经济公式复算购买回本时间、里程碑耗时、增长区间及可能的停滞点；不要只展示无法核验的“爽感曲线”。

## 最小验收证据

用可控时间验证短期收益、离线上限、重复领取、倒退时间和长时数值边界；用真实浏览器检查刷新、后台恢复、余额不足和连续购买。脚本时间模拟与实际浏览器挂起分别报告，环境无法真正冻结时明确未覆盖。此品类无需默认增加解谜求解器或撤销历史。
