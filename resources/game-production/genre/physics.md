# 物理与操作休闲

状态：初始知识指南；本项目尚无该品类完整成品验证。

## 核心状态与循环

状态包含物体位置/速度、碰撞关系、控制输入、目标、检查点和当前局生命周期。循环为观察 → 施加动作 → 物理演化 → 碰撞/命中反馈 → 达标或失败 → 重试。

必须决策：手指控制方式、时间步长、速度/力度范围、碰撞体与画面关系、触发器和碰撞的区分、胜负判定、暂停恢复、重置和防卡死条件。实现先区分是否需要真实物理库，简单抛物线或几何命中也可由小型规则模块完成。

## 规则不变量与关卡

- 结算事件按物体和局生命周期去重；已经结束的局不再领奖，旧回调不得影响新局。
- 物理步进与渲染帧率分离，长帧的补步/截断策略明确；高速度、薄墙与边缘接触必须验证，不假定离散碰撞永不穿透。
- 生成与销毁同步移除物理对象、监听器和表现节点；重试不能累积刚体或旧输入。
- 数值保持有限，越界、落入不可恢复位置或长期静止时按原型约定结束或恢复。
- 难度结合容错窗口、操作次数、障碍布局、速度和反馈延迟。物理结果允许合理误差，按目标平台设定容差，不承诺不同浏览器逐帧位级一致。

## 最小验收证据

覆盖边界碰撞、高速运动、连续输入、命中去重、失败/重试和多次重置后的对象数量。真实界面测试鼠标与触控坐标、不同视口及已承诺帧率条件。自动化轨迹证明机制可运行；操控手感与容错是否合适需真实试玩，不以一条脚本轨迹代替。
