# 方块放置与消行

状态：初始知识指南；本项目尚无该品类完整成品验证。

## 核心状态与循环

状态包含网格占用、待放形状、当前拖拽、得分/目标和生成器状态。循环为选择形状 → 预览合法位置 → 提交放置 → 同时识别并消除满足条件的线或区域 → 计分 → 补充形状或判断结束。

必须决策：棋盘尺寸、形状集合、可否旋转、一次发几块、何时补充、按行列还是区域消除、连击定义、拖拽取消方式，以及失败按“当前形状”还是“所有待放形状”均无位置判断。

## 规则不变量与内容

- 形状格不能重叠或越界；预览和非法释放不改变棋盘、库存和得分。
- 行列交叉同时清除时，每个格只清一次；得分按已定义的组合规则计算，不依赖遍历顺序。
- 一块形状只能消费一次；消除完成后再检查新状态是否无合法位置，避免使用旧棋盘误判。
- 程序生成明确纯随机、权重或保底策略，保存可复现的种子/生成状态。无尽模式允许自然失败，不把“每局保证可解”当默认要求。
- 难度从棋盘占用、洞形、形状分布和可放位置数量分析；关卡模式另外定义目标与可达性验证。

## 最小验收证据

规则覆盖边缘形状、非法放置、行列同时消除、形状补充和无位置判负。真实界面验证拖拽偏移、边界释放、拖出后取消、移动端坐标缩放及一局结束/重开。固定种子复现一段完整序列；若有保底策略，验证其约束而非把它当成胜率承诺。
