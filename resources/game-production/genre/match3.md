# 三消与交换消除

状态：初始知识指南；本项目尚无该品类完整成品验证。

## 核心状态与循环

状态包含棋盘、障碍/特殊块、目标、剩余步数或时间、随机生成状态和结算阶段。循环为交换 → 判断有效性 → 识别匹配与特殊组合 → 消除 → 下落/补充 → 连锁结算 → 检查目标、失败和可行动作。

必须决策：有效交换条件、无效交换是否消耗步数、四连/五连/交叉的特殊块规则、特殊块产生位置、组合效果优先级、目标与步数同时归零时的胜负顺序、死局洗牌方式，以及开始时是否允许自动匹配。

## 规则不变量与关卡

- 同一轮匹配先收集完整集合再结算；交叉格、特殊效果和任务计数不能重复消费。
- 普通交换计一次步数，连锁不额外扣步；实际产品另有规则时写入原型并测试。
- 动画期间锁定相冲突的输入；在稳定棋盘上判断死局、胜负和提示。
- 固定随机种子用于回归；给连锁/特殊效果设置明确终止处理，避免无限结算。
- 难度结合目标、障碍拓扑、步数、颜色数和生成规则。随机补充的关卡用多种子试验评估可达性与分布，不用一条演示解法宣称所有对局必胜。

## 最小验收证据

规则覆盖无效交换回滚、横竖交叉、特殊块组合、连锁、死局、最后一步达标与未达标。真实界面完成一次多轮连锁和结算；记录种子及可复现输入。若产品承诺洗牌保留目标或特殊块，验证这些约束。胜率和难度结论标注样本范围，真人体验仍需实际试玩。
