# 合成与生产链

状态：初始知识指南；本项目尚无该品类完整成品验证。

## 核心状态与循环

状态包含物品身份、类型/等级、格位或容器、生产器/冷却、货币、订单和成长解锁。循环为获得物品 → 摆放或合成 → 完成订单/获得收益 → 解锁下一目标。

必须决策：二合一还是三合一、拖拽与目标物品的处理、跨类型合成、满盘反馈、生产成本、是否有体力/冷却、订单是否重复、出售/删除/撤销策略。2048 类滑动合成应另写整行移动、每次动作合并上限及新块生成规则，不能直接套用拖拽合成。

## 规则不变量与数值

- 校验输入物品仍然存在且可消费，再一次性扣除全部输入并创建输出；失败不能先扣货币或丢失物品。
- 每个物品身份只占一个有效位置；等级、配方、生产器和订单引用合法。
- 奖励领取与订单提交幂等，刷新或重复点击不能重复获利。
- 合成会改变物品数，不要求数量守恒；按配方核对成本、产出和货币流水，资源不得出现非法负值。
- 用“基础投入 → 中间产物 → 订单收益”的可计算链验证目标成本和成长速度；同时考虑格位压力、等待时长和软锁。离线产出存在时读取放置品类的时间规则。

## 最小验收证据

覆盖有效/无效合成、重复提交、满盘、最高等级、生产成本不足、订单消费与奖励，以及存档后身份和冷却恢复。真实界面完成从获取到合成、订单领奖的一条链；用可复算的数值表验证至少一条早期成长路径。仅在包含撤销/出售/离线系统时添加对应测试。
