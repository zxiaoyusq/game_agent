# 原生 Web 技术配置

适用范围：使用 HTML、CSS、ES 模块、DOM/SVG/Canvas 的轻量 H5。选择配置只确定执行契约，不证明当前项目已经生成或通过验收。

## 选择最简单的表现方式

- 棋盘、标记、宝石与几何图案适合 SVG；文本、弹窗、设置与编号按钮优先 DOM 语义；需要持续重绘的场景再用 Canvas。
- 原型说明采用哪一种或怎样组合，不把 SVG 称为 Canvas，也不伪造 Cocos 运行时。
- 规则函数只处理可序列化状态与动作，随机源由外层传入。表现与音效只读已提交状态，不能决定胜负或重复扣除资源。
- 异步动画、AI等待、暂停与视图切换共享清楚的生命周期；新局不能继续执行旧局计时器。

## 工程和交付

遵循 `framework/docs/web-common.md`：提供 `npm run build`、`npm test`、`npm run check`，入口 `dist/index.html`，所有资源相对路径。简单工程可以用短 Node 脚本复制本次源文件，不必引入打包框架。

需要依赖时使用本工作流明确提供的准备工具；不要通过验证脚本绕过工具边界安装软件、读取其他项目或发布到外部目录。没有安装或浏览器能力时如实报告，不把模拟测试写成真实运行。

用户要求小于10MB时，同时计算部署静态目录和完整工程ZIP的压缩前/后字节；明确不包含可由锁文件重建的开发依赖缓存。`reference-inputs/` 仅用于研究，不进入 dist；不得为了节省包体把必需资源移到外部CDN后声称离线完整。

## 验证

- 浏览器真实加载构建，再通过鼠标/触摸/键盘完成开始、核心动作、结算与重开；不能注入胜利状态替代完整循环。
- 检查桌面与移动视窗、无横向溢出、足够大的主要触控目标、弹窗焦点与减少动态效果偏好。
- 检查无失败资源和错误MIME，嵌套部署路径仍能载入；在正式提交状态后存档，坏档与写失败要明确反馈。
- 规则单测与浏览器操作的覆盖范围分别记录；截图仅证明该画面，模拟手机不等于实体真机。

新图像、SVG、程序美术与音效均记录真实路径、来源、用途与SHA256；如果复用了已有资产，标为引用而非模型新生成。
