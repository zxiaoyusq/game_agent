学习索引
把状态、文件与框架职责对应起来
展开概念可回到关联章节。各源码片段取自本页生成时的本机文件，可切换到完整文件阅读上下文。
project / pipeline
整个游戏的计划、四阶段顺序、批准记录与发布设置。保存在 projects/<id>.json。
run / events
某一阶段的模型身份、输入快照、尝试次数、状态、产物与执行证据。保存在 runs/<id>.json。
thread_id / messages
图的检查点身份与消息状态。thread_id 取 run_id，SQLite 保存可恢复的执行进度。
