## 已关闭 P2：完成局切主题重新弹结算并覆盖设置（以下为历史失败证据）

实测最早出现在已真实完成经典第 2 关时，并在累计完成 3、5、6 关时重复出现。

1. 完成经典第 2 关，等待结算，点 × 关闭。
2. 点设置，点击已解锁的默认“暮色海湾”；点击当前主题同样可触发。
3. 等待 800ms。设置被替换成标题“每一种颜色，都有归处”的结算弹窗，副标题为“第 2 关完成 · 14 步 / 再一次找到了秩序”。
4. 星数保持 2、主题仍 0。累计 3 关选第二款、累计 6 关选第三款时，选择会生效，但设置仍在约 650ms 后被对应关卡结算覆盖。

位置：`src/main.mjs` 的 `showSettings()` 主题动作调用 `startLevel({...,won:true})`；`startLevel()` 末尾再次调用 `completeLevel()`，其延迟回调没有区分“主题重绘”与“新胜利”，重新排定结算。用户在完成局选择主题时会被打断。

最小修复方向：主题只重绘既有状态，避免重新触发胜利表现与延迟结算；旧延迟回调应绑定当前会话和预期界面，不能覆盖用户后来打开的设置。回归需真实通关后关结算、开设置、切默认及已解锁主题、等待超过原延时，确认设置保持可操作且星数不变。此为实际操作流程缺陷，不是解锁数据出错。
